## 一、三大财务报表

### 1.1 资产负债表（"体检报告"）

**核心公式**：资产 = 负债 + 所有者权益

| 分类 | 关键科目 |
|------|---------|
| 流动资产 | 货币资金、应收账款、预付账款、存货 |
| 非流动资产 | 固定资产、无形资产（软件/商标） |
| 流动负债 | 应付账款、应付工资、应交税费、短期借款 |
| 所有者权益 | 实收资本、未分配利润 |

**老板看5个指标**：
| 指标 | 公式 | 安全值 | 危险值 |
|------|------|--------|--------|
| 流动比率 | 流动资产÷流动负债 | >2 | <1 |
| 资产负债率 | 负债÷资产 | <50% | >70% |
| 应收占比 | 应收÷资产 | <30% | >30%=坏账风险 |
| 存货占比 | 存货÷流动资产 | <50% | >50%=积压 |
| 现金安全 | 货币资金÷流动负债 | >1 | <1 |

### 1.2 利润表（"成绩单"）

```
营业收入
- 营业成本
= 毛利润（毛利率<30%=选品/定价有问题）
- 销售费用（广告/物流/平台费）
- 管理费用（工资/办公/差旅）
- 研发费用
- 财务费用
= 营业利润
± 营业外收支
= 利润总额
- 所得税
= 净利润（这才是真正落袋的钱）

⚠️ 老板常犯错：只看毛利率40%，但广告+退货+仓储吃掉35%，净利率只有5%
```

### 1.3 现金流量表（"为什么赚钱但没钱"）

**5个原因**：
1. **应收账款**：货发了钱没收到（Amazon 14天打款一次）
2. **存货占用**：FBA库存=最大现金黑洞
3. **预付账款**：提前付供应商定金
4. **固定资产**：利润表只体现折旧，现金一次出去
5. **利润≠现金**：权责发生制vs收付实现制

**健康判断**：经营净现金流 > 净利润 = 利润质量高

### 2.1 软件选择

| 营收规模 | 推荐 | 费用 |
|---------|------|------|
| <100万 | 柠檬云/浪潮云免费版 | 免费 |
| 100-500万 | 用友畅捷通好会计 | ¥800/年 |
| >500万 | 金蝶/用友标准版 或 代账公司 | ¥500-1,500/月 |

⚠️ 不推荐Excel手工账：税务不认可+无法自动生成报表

### 2.2 做账5步

```
1. 收集原始凭证（发票/银行回单/合同）
2. 编制记账凭证（确定借贷科目）
3. 登记明细账（按科目逐笔）
4. 汇总总账（月末，软件自动）
5. 编制报表（软件自动生成）
```

### 2.3 简易账
- ✅ 小企业会计准则适用（资产<4亿+人数<300）
- 科目简化+报表简化（资产负债表+利润表即可）
- ⚠️ 简易≠随便：仍需完整凭证+按月做账+按时申报

## 三、发票管理

### 3.1 全电发票（2025年全国推广）
- **无需税控盘**！登录电子税务局在线开票
- 与纸质发票同等法律效力
- 开错不能直接作废→开红字发票冲回

### 3.2 进项抵扣（一般纳税人）
- ✅ 可抵扣：增值税专票、海关缴款书、旅客运输发票
- ❌ 不能抵扣：普通发票、集体福利/个人消费、餐饮/娱乐
- ⚠️ 小规模纳税人不需要抵扣（简易计税）

### 3.3 认证期限
- 全电发票：**无期限限制**（但建议当月勾选）
- 纸质专票：开票日起360天内
