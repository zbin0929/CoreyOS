## 一、Amazon运营深度解析

### 1.1 A9/A10算法深度拆解

**A10算法核心变化（2024-2026）**：

| 维度 | A9（旧） | A10（新） | 运营启示 |
|------|---------|----------|---------|
| 销售速度权重 | ★★★★★ | ★★★★★ | 不变，仍是第一因素 |
| 广告出单权重 | ★★★★ | ★★★☆ | 广告依赖度降低，自然出单更重要 |
| 站外引流权重 | ★★ | ★★★★ | TikTok/Instagram引流有排名加成 |
| 买家行为信号 | ★★★ | ★★★★★ | 停留时间、加购率、回购率都算 |
| 卖家权威度 | ★★ | ★★★★ | 老店+好绩效有排名优势 |
| 评论增长速度 | ★★★ | ★★★★ | 评论"增速"比绝对数量更重要 |

**A10排名公式（简化模型）**：
```
排名得分 = 关键词相关性 × (自然出单×1.5 + 广告出单×1.0 + 站外出单×1.3)
         × 转化率 × 买家行为分 × 卖家权威分
         ÷ 退货率惩罚
```

**关键词相关性权重层级**：
```
第1层：标题（Title）         → 权重最高，占60%+
第2层：五点描述（Bullets）    → 权重中等，占15-20%
第3层：后台搜索词（Search Terms）→ 权重中等，占10-15%
第4层：A+/描述（Description） → 权重低，占5-10%
第5层：Subject Matter        → 补充关键词
第6层：Intended Use          → 场景关键词

⚠️ 重要：同一个关键词只需出现在一个层级中，不需要重复堆砌。
A10理解词义变体（yoga mat = yoga mats = yoga pad）
```

### 1.2 新品上架28天蜜月期SOP

**蜜月期本质**：Amazon对新品给予额外曝光机会，测试其市场表现。

```
Day 0-3: 准备期
├─ Listing上线，所有内容已就绪（标题/五点/A+/主图/副图/视频）
├─ FBA库存到仓，状态Active
├─ 开启自动广告（竞价=建议竞价×0.8，日预算$30-50）
└─ 设置Coupon（10-15%off，吸引首批点击）

Day 4-7: 数据收集期
├─ 自动广告跑出搜索词报告
├─ 分析CTR（>0.4%的词=好词）
├─ 分析CVR（>10%的词=出单词）
├─ 识别无效花费词（花费>$5无点击/花费>$10无转化）
└─ 申请Vine（最多30个免费评论名额）

Day 7-14: 精准打击期
├─ 开手动精准匹配广告（出单词，竞价=建议竞价×1.2）
├─ 开手动广泛匹配广告（潜力词，竞价=建议竞价×0.8）
├─ 自动广告否定已转手动的精准词（避免内部竞争）
├─ 否定无效词（Negative Exact）
├─ Top of Search加价30-50%（抢首页首位）
└─ 目标：每天10-20单出单速度

Day 14-21: 排名冲刺期
├─ 核心大词精准匹配加价（目标自然排名前3页）
├─ 站外引流辅助（TikTok/Instagram/Deal网站）
├─ Vine评论开始到达（目标：15+条）
├─ 使用Brand Analytics看搜索词报告
├─ 优化主图（A/B测试CTR）
└─ 确认补货时间线（FBA断货=排名暴跌）

Day 21-28: 稳固排名期
├─ 核心词自然排名进入前3页=成功
├─ 逐步降低广告竞价（已有自然排名加持）
├─ ACoS开始下降，TACOS趋于稳定
├─ 继续积累评论（Request a Review按钮）
└─ 开启SB品牌广告（有品牌备案）
```

**28天关键指标目标**：

| 指标 | Day 7目标 | Day 14目标 | Day 28目标 |
|------|----------|-----------|-----------|
| 日均出单 | 5-10 | 10-20 | 15-30 |
| 核心词排名 | 前10页 | 前5页 | 前3页 |
| 评论数 | 0-2 | 5-10 | 15-30 |
| ACoS | 50-80% | 30-50% | 20-35% |
| CVR | 8-12% | 10-15% | 12-18% |

### 1.3 关键词排名打法

**螺旋式排名法（Ranking Spiral）**：
```
核心思路：用广告出单带动自然排名，然后降低广告依赖

Week 1: 高竞价广泛匹配 → 收集出单词
Week 2: 中竞价精准匹配 → 打特定关键词
Week 3: 高竞价精准匹配 + Top of Search → 冲排名
Week 4: 降竞价 → 自然排名接力 → 看TACOS是否下降

健康指标：TACOS（广告花费÷总销售额）持续下降 = 自然出单占比上升
```

**不同竞争程度的打法**：

| 竞争程度 | 关键词特征 | 打法 | 预算 |
|---------|----------|------|------|
| 蓝海词 | 月搜索量<5K，竞品少 | 精准匹配+低竞价，2周冲首页 | $10-20/天 |
| 中等词 | 月搜索量5K-50K | 精准匹配+中竞价+Top of Search | $30-50/天 |
| 红海大词 | 月搜索量>50K | 先打长尾→再攻大词，需4-8周 | $50-100/天 |

**关键词分层策略**：
```
Tier 1: 核心转化词（3-5个）  → 精准匹配，不惜代价打排名
Tier 2: 高流量词（10-15个）  → 精准+广泛匹配，控制ACoS
Tier 3: 长尾流量词（30-50个）→ 广泛匹配/自动广告，低竞价捡漏
Tier 4: 防守词（品牌词+ASIN定位）→ 品牌广告+SD广告，防竞品截流
```

### 1.4 Listing优化高阶技巧

**标题优化A/B测试**：
- Amazon "Manage Your Experiments" 功能（需品牌备案）
- 同时跑两个标题版本，看哪个CTR/CVR更高
- 测试周期：至少2周，样本量>1000次曝光
- 常见测试变量：核心词位置、属性词选择、标题长度

**主图CTR优化**：
```
主图CTR = 点击数 ÷ 曝光数

影响因素排序：
1. 产品角度（45度角通常最好）
2. 产品占画面比例（85%+）
3. 白底纯净度（纯白=RGB 255,255,255）
4. 色彩对比度（与白底形成反差）
5. 产品状态（使用状态 vs 静态）

技巧：
- 同品类竞品主图都是正面 → 你用侧面/45度角，差异化
- 加一个"小配件"在旁边暗示包含什么
- 高端品用深色调产品拍摄（奢侈感）
```

**五点描述转化公式**：
```
每一条五点 = [大写关键词短语] + 痛点描述 + 产品如何解决 + 具体数据/认证

示例：
[ANTI-SLIP YOGA MAT] Tired of slipping during hot yoga? Our 6mm thick
TPE mat features a dual-texture surface that provides 3x more grip than
standard PVC mats, even when wet. SGS certified non-toxic.

公式：关键词 + 痛点 + 解决方案 + 数据背书
```

**A+页面最佳实践**：
```
模块顺序（8-12个模块）：
1. 品牌故事Banner（品牌调性）
2. 核心卖点对比图（你 vs 普通产品）
3. 使用场景图（3-4个场景）
4. 产品细节特写（材质/工艺）
5. 尺寸/参数信息图
6. 包装清单（含什么配件）
7. 用户证言（真实使用效果）
8. FAQ（解答常见顾虑）
9. 品牌其他产品交叉推荐

⚠️ A+页面 SEO 注意：
- A+描述里的文字 Amazon 会索引
- 但权重低于标题/五点/后台Search Terms
- A+主要目的是提升CVR，不是SEO
```

## 二、Shopee运营深度解析

### 2.1 Shopee搜索排名算法

**Shopee搜索排名因素（权重排序）**：

| 排名 | 因素 | 权重 | 运营启示 |
|------|------|------|---------|
| 1 | 关键词匹配度 | ★★★★★ | 标题前40字符最关键 |
| 2 | 销量 | ★★★★★ | 近7天销量>30天>90天 |
| 3 | 转化率 | ★★★★ | 高CVR的商品排名靠前 |
| 4 | 店铺评分 | ★★★★ | 4.8+店铺有流量加权 |
| 5 | 聊天回复率 | ★★★☆ | 回复率>90%、回复速度<5分钟 |
| 6 | 物流评分 | ★★★☆ | 发货速度+物流时效 |
| 7 | 价格竞争力 | ★★★☆ | 同品类价格排名 |
| 8 | 商品完整度 | ★★☆☆ | 图片数量/视频/描述完整度 |

**Shopee标题优化公式**：
```
[核心关键词] + [属性1] + [属性2] + [适用场景] + [品牌/特色]

限制：
- 总长度：建议50-120字符（不同站点限制不同）
- 前40字符最重要（移动端截断显示）
- 不要堆砌无关关键词（会被降权）
- 使用Shopee关键词广告后台查搜索量

示例：
猫砂盆 全封闭式 超大号 防溅防臭 猫厕所 自动除臭 适合胖猫
[核心词] [属性]  [属性] [卖点]  [同义词] [特色]  [场景]
```

## 三、TikTok Shop运营深度解析

### 3.1 TikTok推荐算法

**For You Feed算法核心**：
```
推荐公式（简化）：
推荐权重 = 完播率×40% + 互动率×25% + 分享率×15% + 评论率×10% + 关注率×10%

关键指标：
- 完播率（Watch Through Rate）：视频被完整看完的比例 → 最重要
- 互动率：点赞+评论+分享+收藏 ÷ 播放量
- 分享率：分享数÷播放量 → TikTok最看重的互动指标
- 账号权重：历史表现、发布频率、垂直度
```

**TikTok流量池机制**：
```
第1级流量池：200-500播放 → 2小时内测试
  ├─ 完播率>30% + 互动率>3% → 进入下一级
  └─ 未达标 → 停止推荐

第2级流量池：1K-5K播放 → 6小时内测试
  ├─ 完播率>25% + 互动率>5% → 进入下一级
  └─ 未达标 → 停止推荐

第3级流量池：1W-10W播放 → 12小时内测试
  ├─ 指标持续优秀 → 进入下一级
  └─ 未达标 → 停止推荐

第4级流量池：10W-100W播放 → 24小时内
第5级流量池：100W+播放 → 爆款

关键：前2小时的数据决定生死
```

### 3.2 TikTok Shop电商运营模式

**三大变现路径**：

| 模式 | 说明 | 适合谁 | 利润空间 |
|------|------|--------|---------|
| 短视频带货 | 商品橱窗+视频挂链接 | 有内容能力的卖家 | 高（内容成本低） |
| 直播带货 | 实时直播展示商品 | 有直播团队/达人 | 中-高 |
| 达人合作 | 寄样给达人，达人拍视频/直播 | 有产品无内容能力 | 中（需付佣金） |

**达人合作全流程**：
```
Step 1: 寻找达人
├─ TikTok Creator Marketplace（官方平台）
├─ 手动搜索相关品类达人（粉丝1K-100K最性价比）
├─ 筛选标准：粉丝量、互动率(>3%)、内容匹配度、GMV/视频
└─ 建议同时联系20-50个达人（回复率约10-20%）

Step 2: 联系洽谈
├─ 通过达人广场站内信 或 Bio里的联系方式
├─ 合作模式：纯佣金(10-30%) / 寄样+佣金 / 坑位费+佣金
├─ 新手建议：纯佣金模式（零风险）
└─ 提供：产品信息/卖点/建议脚本/样品

Step 3: 寄样+跟进
├─ 海外仓直发样品（时效快）
├─ 附上产品说明+拍摄建议（不是要求，是建议）
├─ 收到样品后3天跟进一次
└─ 给达人创作自由（他们更懂自己粉丝）

Step 4: 数据跟踪
├─ 视频发布后24小时内关注播放量
├─ 48小时内看GMV转化
├─ 记录每个达人的ROI
└─ 优质达人建立长期合作关系
```

### 3.3 TikTok短视频内容公式

**爆款视频结构（15-60秒）**：
```
0-3秒：Hook（钩子）→ 决定用户是否继续看
├─ 问题式："为什么你的猫总是挑食？"
├─ 数字式："3个技巧让你的瑜伽进步10倍"
├─ 反差式：先展示痛点/丑/乱 → 再展示解决方案/美/整洁
├─ 悬念式："我用了这个东西之后..."
└─ 视觉冲击：产品特殊功能的惊艳展示

3-15秒：展示产品
├─ 使用场景（而非产品硬照）
├─ 多角度切换（每2-3秒一个镜头）
└─ 加字幕（80%用户静音观看）

15-45秒：深入卖点
├─ 解决了什么问题
├─ Before vs After
├─ 与竞品对比
└─ 用户证言/评价截图

最后3-5秒：CTA（行动号召）
├─ "Link in bio" / "Check the yellow cart"
├─ 限时优惠："50% off today only"
└─ 互动引导："Comment your size below"
```

**内容矩阵策略**：
```
每周发布计划（建议5-7条/周）：
├─ 2条 产品展示视频（核心款）
├─ 1条 使用教程/Tips视频
├─ 1条 客户评价/UGC重拍
├─ 1条 幕后/工厂/打包过程
└─ 1-2条 蹭热点/挑战/趋势

比例原则：80%内容价值 + 20%硬广
```

## 四、其他平台运营要点

### 4.1 Temu运营策略

**Temu模式特殊性**：
```
全托管模式：
- 卖家只负责：供货、报价、品质
- 平台负责：定价、流量、物流、售后
- 卖家不控制零售价（平台定价）
- 卖家利润 = 供货价 - 成本 - 头程

半托管模式（2025年推出）：
- 卖家：供货 + 定价 + 物流（海外仓发货）
- 平台：流量分配
- 卖家有更多控制权，但需要海外仓库存
```

**Temu供货核心策略**：

| 策略 | 说明 | 适合 |
|------|------|------|
| 极致成本 | 压缩每一分钱成本，靠走量赚钱 | 工厂型卖家 |
| 差异化供货 | 提供市场上少见的款式/功能 | 贸易商/设计能力 |
| 快速跟品 | 看平台热卖品→快速供货 | 柔性供应链 |
| 季节性供货 | 提前备货季节性产品 | 有经验的卖家 |

## 五、多平台运营策略

### 5.1 多平台扩展路径

```
阶段1（0-6个月）: 单平台精通
├─ 选择一个平台做到稳定出单
├─ 建立标准化运营SOP
├─ 积累供应链和物流经验
└─ 月销售额达到$5K-10K

阶段2（6-12个月）: 双平台布局
├─ 第一平台稳定 → 开第二平台
├─ 推荐组合：Amazon + Shopee / Amazon + TikTok Shop
├─ 共用供应链，降低边际成本
├─ 注意：两个平台的运营逻辑不同，需要分别投入
└─ 月销售额达到$15K-30K

阶段3（12-24个月）: 多平台矩阵
├─ 3-4个平台同时运营
├─ 独立站（Shopify）开始建设品牌
├─ 考虑招人/外包部分运营
├─ 海外仓+FBA组合使用（库存共享）
└─ 月销售额达到$50K-100K

阶段4（24个月+）: 品牌化+全渠道
├─ 独立站成为品牌主阵地
├─ 各平台作为分销渠道
├─ DTC（Direct to Consumer）模式
├─ 线下零售/批发拓展
└─ 品牌溢价 → 利润率提升
```

### 5.2 多平台库存分配策略

| 策略 | 说明 | 适合场景 |
|------|------|---------|
| FBA+海外仓并行 | FBA满足Amazon，海外仓供其他平台 | 多平台卖家 |
| 集中海外仓 | 一个海外仓发所有平台 | 初期节省成本 |
| 国内直发+海外仓 | 海外仓发热卖品，国内直发长尾品 | SKU多的卖家 |
| 平台仓各自备货 | FBA/WFS/SLS各自备货 | 各平台销量都大 |

**库存分配公式**：
```
各平台备货量 = 日均销量 × 补货周期天数 × 安全系数

安全系数：
- 稳定期：1.5倍
- 大促前：2.5-3倍
- 新品期：1.0倍（不过度备货）

示例：
Amazon日销20件，补货周期45天 → 20×45×1.5 = 1350件
Shopee日销10件，补货周期30天 → 10×30×1.5 = 450件
```

## 七、账号健康管理全平台对照

| 指标 | Amazon | Shopee | TikTok Shop | 后果 |
|------|--------|--------|------------|------|
| 订单缺陷率 | <1% (ODR) | N/A | N/A | >1%=封店风险 |
| 迟发率 | <4% | <5% | <5% | 影响流量+罚款 |
| 取消率 | <2.5% | <2% | <3% | 影响店铺评分 |
| 回复时效 | 24h | 12h | 24h | 影响绩效+排名 |
| 退货率 | 品类不同 | <根据品类 | <根据品类 | 高退货=降权 |
| 知识产权投诉 | 零容忍 | 零容忍 | 零容忍 | 直接封店 |
| 评分要求 | >4.0 | >4.5 | >4.0 | 低评分=流量骤降 |

**账号安全红线（任何平台）**：
```
绝对不能碰：
❌ 刷单/刷评（所有平台零容忍）
❌ 侵权产品（专利/商标/版权）
❌ 虚假广告/虚假发货
❌ 多账号关联（同一人/IP/设备开多店）
❌ 操纵价格（标高价再打折、与其他卖家串通定价）
❌ 滥用退款/保险

可能触发审查：
⚠️ 短期内销量暴增（>正常的300%）
⚠️ 产品与描述严重不符
⚠️ 大量同IP/同收货地址购买
⚠️ 频繁修改关键产品信息
```
