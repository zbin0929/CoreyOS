# 中国小微企业税务实操

> 核心观点：小型微利企业5%税率 vs 标准25%，300万是悬崖线。

---

## 一、小微企业认定标准（2025-2026最新）

**两个概念别搞混**：

| 概念 | 认定标准 | 享受优惠 |
|------|---------|---------|
| 小型微利企业 | 年利润≤300万 + 人数≤300 + 资产≤5000万 | 企业所得税5% |
| 小规模纳税人 | 年应税销售额≤500万 | 增值税简易计税+免税 |

### 1.1 税收优惠全景

| 税种 | 优惠政策 | 有效期 |
|------|---------|--------|
| 企业所得税 | ≤300万部分实际税率5% | 至2027年底 |
| 增值税 | 月销≤10万免征 | 长期 |
| 增值税 | 3%减按1%征收 | 至2027年底 |
| 六税两费 | 减半征收 | 至2027年底 |
| 残保金 | 在职≤30人免征 | 长期 |

**年利润100万对比**：
- 标准企业：100万×25% = **25万税**
- 小型微利：100万×5% = **5万税**（省20万！）

## 二、增值税：小规模 vs 一般纳税人

| 维度 | 小规模纳税人 | 一般纳税人 |
|------|-------------|-----------|
| 认定 | 年销售额≤500万 | >500万或主动申请 |
| 计税 | 销售额×1%（减按） | 销项税-进项税 |
| 进项抵扣 | ❌ 不能 | ✅ 可以 |
| 免税 | 月销≤10万免征 | 无 |
| 申报 | 季度 | 月度 |
| 适合 | 进项少/服务型/初创 | 进项多/贸易型/需专票 |

### 什么时候该转一般纳税人？

```
判断公式：进项占销售额比例 > 92% → 一般纳税人可能更划算

实际上大多数小微企业，小规模更划算！
因为1%征收率极低，一般纳税人很难更省

例外：
- 进项占比极高（>92%）的纯贸易企业
- 客户要求开13%专票
```

### 增值税免税额度

```
月销售额≤10万（季度≤30万）→ 免征增值税

⚠️ 10万是"悬崖线"！
10万免税，10.01万全额缴税

月销8万 → 免税
月销12万 → 全额：12万×1% = 1,200元

接近10万时的策略：推迟开票到下月、拆分合同
```

## 三、企业所得税

### 3.1 小型微利企业优惠税率

```
应纳税所得额≤300万：实际税率5%
计算：应纳税所得额 × 25% × 20% = 5%

标准税率25% vs 小型微利5% → 省80%！
```

### 3.2 300万悬崖效应

```
299万：所得税 = 299万×5% = 14.95万 → 税后284.05万
301万：所得税 = 301万×25% = 75.25万 → 税后225.75万

多赚2万，多缴60.3万！税后少了58.3万！

规划方法（接近300万时）：
1. 增加研发费用（加计扣除100%）
2. 增加员工福利
3. 增加广告宣传费
4. 增加办公设备采购（一次性扣除）
5. 拆分业务到两个公司（注意"实质重于形式"）
```

### 3.3 研发费用加计扣除

**什么算研发费用？**

| 行业 | 可算研发 | 不算研发 |
|------|---------|---------|
| 跨境电商 | 开发选品算法/ERP/智能客服/数据分析系统 | 用现成工具做选品/买现成ERP |
| 软件/AI | 开发新算法模型/新产品/优化架构/训练微调模型 | 调用现成API/修Bug/运维 |

**加计扣除100%计算**：
```
研发费用30万 → 加计扣除30万 → 应纳税所得额减少30万
省税 = 30万 × 5%(小微税率) = 1.5万
如果是25%标准税率：省7.5万

⚠️ 最大价值：帮你控制在300万以内！
例：利润310万 + 研发费20万加计扣除 → 290万
   税从77.5万降到14.5万，省63万！
```

**必备材料**：
1. 项目立项（决议+计划书+审批）
2. 研发过程（人员名单+工时+日志+测试报告+代码仓库）
3. 费用归集（辅助账+工资表+采购发票+折旧表）
4. 成果证明（软著/专利/上线截图）
5. 申报表（A107012）

**实操建议**：年初立项、单独建账、过程留痕、按工时比例分摊（60%研发+40%运营→只算60%）、外包只按80%扣除

## 四、社保公积金实操

### 4.1 最低缴纳基数

```
基数范围：当地社平工资的60%-300%
实际工资<最低基数 → 按最低基数缴
实际工资>最高基数 → 按最高基数缴
```

**2025年主要城市参考**：

| 城市 | 养老最低基数 | 企业月缴约 | 个人月缴约 |
|------|------------|-----------|-----------|
| 北京 | ¥6,326 | ¥2,200 | ¥1,100 |
| 上海 | ¥7,310 | ¥2,500 | ¥1,270 |
| 深圳 | ¥2,360 | ¥1,500 | ¥800 |
| 杭州 | ¥4,462 | ¥1,500 | ¥800 |

### 4.2 灵活用工方式

| 方式 | 社保责任 | 成本 | 适合 |
|------|---------|------|------|
| 正式员工 | 企业全额缴 | 最高 | 核心岗位 |
| 劳务外包 | 外包公司缴 | 中高（含5-15%管理费） | 非核心岗位 |
| 劳务派遣 | 派遣公司缴 | 中 | 临时性/辅助性（≤10%） |
| 兼职/劳务协议 | 个人自缴 | 最低 | 项目制/临时性 |

**兼职税务处理**：
- ≤800元/次：免个税
- 800-4000：减800后×20%
- \>4000：减20%后×20-40%累进

**风险**：固定时间上班+受直接管理+长期只服务一家 → 可能被认定事实劳动关系 → 补缴社保

## 五、常见合规风险TOP5

### 风险1：个人账户收款
- **触发**：客户转账到个人微信/支付宝/银行卡、用个人PayPal收跨境收入
- **后果**：补税+滞纳金+0.5-5倍罚款、账户冻结、有限责任失效、逃税罪(>10万)
- **正确做法**：开对公账户、所有收入进对公、老板拿钱只有3条路（工资/分红/借款）

### 风险2：公私不分
- **触发**：公司账户付个人消费、公司资产登记个人名下、无记录向老板转钱
- **后果**：一人有限公司有限责任失效、税务稽查全面审查、职务侵占
- **正确做法**：公私账户严格分开、报销要有业务关联、资产登记公司名下

### 风险3：发票虚开
- **触发**：买发票、卖发票、内容不符、金额不符
- **后果**：虚开增值税专票罪——税款1-10万→3年以下、10-50万→3-10年、>50万→10年以上/无期
- **正确做法**：四流一致（合同流/资金流/物流/发票流）、绝不买卖发票

### 风险4：未申报收入
- **触发**：不开票不申报、海外收入不申报、微信收款不记账、阴阳合同
- **后果**：滞纳金年化18.25%上不封顶、罚款0.5-5倍、CRS信息交换让海外收入无处藏
- **正确做法**：所有收入如实记账（开票/不开票都要）、海外收入中国申报（可抵免）、主动补报（罚0.5倍vs被查1-5倍）

### 风险5：社保逃缴
- **触发**：不缴/少缴/晚缴、只缴部分险种、"自愿放弃"协议（无效！）
- **后果**：补缴无时效限制、工伤赔偿全部企业承担（严重工伤>100万）、员工可随时投诉
- **正确做法**：入职30天办社保、试用期也要缴、买雇主责任险(¥200-800/人/年)

---

> **核心总结**：小微企业身份极其宝贵——5%所得税+1%增值税+免税额度，比大企业省80%税。300万和10万是两条悬崖线。研发费用加计扣除的最大价值是保住小微身份。灵活用工可降低社保成本但要注意合规边界。
