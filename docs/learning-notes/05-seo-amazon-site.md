## 一、Amazon站内SEO

### 1.1 A9/A10算法排名因素

**第1梯队（决定性）**：
| 因素 | 权重 | 说明 |
|------|------|------|
| 销售速度 | ★★★★★ | 近7天>30天>90天（A10更重视近期） |
| 转化率 | ★★★★★ | 点击后购买比例 |
| 关键词相关性 | ★★★★★ | 标题>五点>后台搜索词>描述 |

**第2梯队（重要）**：
| 因素 | 权重 | 说明 |
|------|------|------|
| 点击率(CTR) | ★★★★☆ | 主图+标题+价格+评论数 |
| 评论数和评分 | ★★★★☆ | A10看评论增长速度 |
| 广告销售额 | ★★★★☆ | 自然出单权重>广告出单 |

**A10 vs A9关键区别**：更重视站外引流、降低广告权重、更重视近期销量、增加用户行为信号

### 1.2 标题优化公式

```
品牌名 + 核心关键词 + 核心属性1 + 核心属性2 + 使用场景 + 颜色/尺寸

例：Gaiam Yoga Mat - Non-Slip, 6mm Thick, Eco Friendly TPE,
with Carrying Strap - for Hot Yoga, Pilates & Home Workout,
72"x24", Black

规则：
1. 长度150-200字符
2. 前80字符包含最重要关键词（移动端只显示这么多）
3. 可读性>关键词密度
4. 不重复关键词（A9理解词义变体）
5. 仅首字母大写
```

### 1.3 五点描述公式

```
格式：[大写卖点关键词] + 功能描述 + 用户收益

Point 1: 最核心卖点（解决最大痛点）
Point 2: 第二核心卖点
Point 3: 材质/品质
Point 4: 使用场景/多功能性
Point 5: 附加价值/保障

技巧：先功能后收益、用具体数字、自然融入关键词、暗含解决差评痛点
```

### 1.4 Search Terms填写

```
限制：250字节（字母1字节/中文3字节）
- 不重复标题中已有的词！
- 用空格分隔，不用逗号
- 单数复数只写一个
- 不需要品牌名/虚词
- 填满250字节（一个都不浪费）
```

### 1.5 排名提升TOP10

1. **提升销售速度**：广告+站外引流+Deal冲量
2. **提升转化率**：优化主图(CTR)+五点/A+(CVR)，目标CVR>10%
3. **打核心关键词排名**：精准匹配+Top of Search加价，持续2-4周
4. **获取评论**：Vine+Request a Review+Insert Card，前30天15+条
5. **避免断货**：提前60天备货
6. **优化主图CTR**：A/B测试，目标>0.5%
7. **站外引流**：TikTok/Instagram/红人
8. **价格竞争力**：Coupon代替直接降价
9. **账号健康**：ODR<1% / 迟发率<4% / 取消率<2.5%
10. **持续优化**：每月查关键词覆盖、每季度更新A+

## 二、独立站SEO

### 2.1 站内优化Checklist

**TDK**：
- Title：50-60字符，含核心关键词+品牌名，每页唯一
- Meta Description：150-160字符，吸引点击
- Keywords Meta：Google已不用（Bing仍参考）

**URL优化**：
- ✅ `/products/non-slip-yoga-mat`
- ❌ `/products/p-12345`
- 简短(3-5词)、连字符、全小写

**内链策略**：产品页→相关产品、博客→产品页、分类→子分类、锚文本含关键词

**H标签层级**：H1每页1个=核心关键词，不跳级(H1→H2→H3)

**Schema标记**：Product/Review/FAQ/Breadcrumb/Organization Schema

**图片Alt**：描述内容+包含关键词，非"image1"

### 2.2 站外SEO（外链建设）

#### 4大外链建设策略

```
策略1：Guest Post（客座博客）——最主流
  流程：
    1. Google搜索 "[keyword] + write for us/guest post/contribute"
    2. 筛选：DA>30 + 流量>5K/月 + 行业相关 + 非PBN
    3. 发Pitch邮件（提供3个选题+简介）
    4. 撰写1500-2500字原创文章，自然插入1-2个链接，锚文本多样化
    5. 发布后社交分享+回复评论+建立长期关系
  费用：免费~$500/篇（高端DA50+网站$500-2000）

策略2：HARO（Help A Reporter Out）——高DA媒体外链
  平台：connectively.us（原haro.com），免费/$19-149/月
  流程：每天筛选记者需求→24-48h内快速回复→获得DA60-90+媒体链接
  等价价值：$200-2000/条

策略3：资源页链接（Resource Page）
  搜索 "[keyword] + inurl:resources/useful links"→筛选DA>20→邮件申请加入
  成功率：5-15%

策略4：竞品外链分析
  Ahrefs/SEMrush输入竞品域名→查Referring Domains→按DR排序→分类复制
  类型：Guest Post/资源页/目录/媒体报道

节奏：新站5-10条/月 | 成长期10-20条/月 | 成熟期20-50条/月
⚠️ 禁忌：不买外链 | 不用PBN | 不大量低质量 | 不过度优化锚文本
```

#### 外链质量评估

| 指标 | 来源 | 范围 | 标准 |
|------|------|------|------|
| DA(Domain Authority) | Moz | 1-100 | <20低 / 20-40中 / 40-60良 / 60-80优 / >80顶级 |
| PA(Page Authority) | Moz | 1-100 | 单页面权威性，比DA更精确 |
| TF(Trust Flow) | Majestic | 0-100 | >20可信，基于高质量链接距离 |
| CF(Citation Flow) | Majestic | 0-100 | TF/CF>0.5健康，<0.3可疑 |

```
高质量外链特征：DA40+ + 行业相关 + 正文内链接 + Dofollow + 锚文本自然 + 有真实流量
```

#### 外链分析工具

| 工具 | 核心优势 | 外链数据库 | 定价 |
|------|---------|-----------|------|
| Ahrefs | 数据库最大(15万亿+)、更新最高、DR指标、断链建设 | 最大 | $99-999/月 |
| Moz | DA/PA行业标准、Spam Score、界面友好 | 中等 | $99-599/月 |
| SEMrush | 外链审计最强、综合SEO工具、Backlink Gap | 大 | $119-449/月 |

**推荐**：Ahrefs（外链建设首选）

#### 社交信号和品牌提及

```
直接影响有限（Google官方表示非排名因素）
间接影响显著：社交分享→曝光→更多外链 | 品牌认知→品牌搜索 | 流量→行为信号

品牌提及（Brand Mention）：未链接的提及也有SEO价值
  → 监控：Google Alerts / Brand24
  → 联系提及方请求添加链接
  → 主动创造被提及机会（PR/活动/研究）

提升策略：每篇文章分享3-5个平台 | 添加分享按钮 | 创建可分享内容(信息图/数据) | 红人合作
```

### 2.3 技术SEO

#### Core Web Vitals

```
1. LCP(Largest Contentful Paint)：最大内容渲染时间
  目标：<2.5秒(好) | 2.5-4秒(需改善) | >4秒(差)
  优化：WebP压缩 + CDN(Cloudflare) + TTFB<200ms + preload/preconnect + lazy loading

2. INP(Interaction to Next Paint，2024起替代FID)：交互响应时间
  目标：<200ms(好) | 200-500ms(需改善) | >500ms(差)
  优化：减少JS执行时间 + Code Splitting + defer/async + 减少第三方脚本 + Web Workers

3. CLS(Cumulative Layout Shift)：视觉稳定性
  目标：<0.1(好) | 0.1-0.25(需改善) | >0.25(差)
  优化：图片/视频设宽高 + 广告位预留 + font-display:swap + 避免动态注入

检测工具：PageSpeed Insights | Search Console | GTmetrix | WebPageTest | Lighthouse

Shopify/WordPress优化清单：
  ☑ TinyPNG/ShortPixel压缩 | ☑ Cloudflare CDN | ☑ lazy loading
  ☑ 减少第三方脚本 | ☑ Gzip/Brotli | ☑ 最小化CSS/JS
  ☑ 浏览器+服务器缓存 | ☑ 快速主题 | ☑ VPS>共享主机
```

#### 移动端优化

```
Google Mobile-First Indexing：移动版优先索引+排名
清单：
  ☑ 响应式设计 | ☑ 正文≥16px | ☑ 按钮≥48×48px | ☑ 间距≥8px
  ☑ 无水平滚动 | ☑ 图片自适应 | ☑ 表格简化 | ☑ 弹窗不遮挡
检测：Google Mobile-Friendly Test | Chrome DevTools | 真机多设备测试
```

#### 网站架构和URL

```
架构原则：扁平化(3次点击内可达) + 逻辑层级(首页→分类→子分类→产品) + 充分内链

URL规则：小写+连字符+含关键词+<60字符+无参数
  ✅ /products/wireless-earbuds | /blog/best-running-shoes
  ❌ /p/12345 | /category?id=5&sort=price

电商架构示例：
  首页 → /collections(分类) → /products(产品页)
       → /pages(About/Shipping/Returns)
       → /blogs(News/Guides)
```

#### XML Sitemap和Robots.txt

```
Sitemap：告诉搜索引擎可索引页面，加速发现
  包含：重要页面 | 不包含：404/重定向/分页/排序/搜索结果
  Shopify自动生成：yourbrand.com/sitemap.xml
  提交到Google Search Console

Robots.txt：
  User-agent: *
  Disallow: /admin | /cart | /checkout | /search | /account
  Sitemap: https://yourbrand.com/sitemap.xml
  ⚠️ 不要禁止CSS/JS（Google需要渲染页面）
```

#### 结构化数据（Schema Markup）

```
作用：Rich Snippets(富媒体搜索结果)，CTR提升20-30%

电商常用：Product(价格/评分/库存) | Review(星级) | FAQ(展开) | BreadcrumbList | Organization | Article

实施：Shopify用"JSON-LD for SEO"插件 | WordPress用Rank Math/Yoast
检测：Google Rich Results Test | Search Console增强功能
```

#### HTTPS和安全

```
HTTPS必须(Google排名因素) | Shopify默认 | WordPress用Let's Encrypt免费SSL
清单：☑ HTTPS全站 | ☑ HTTP→HTTPS 301 | ☑ 混合内容修复 | ☑ HSTS | ☑ 更新CMS/插件 | ☑ WAF
```

#### 国际SEO（hreflang）

```
hreflang告诉搜索引擎页面的语言/地区版本，避免重复内容
  <link rel="alternate" hreflang="en-US" href="..."/>
  <link rel="alternate" hreflang="x-default" href="..."/>

多语言网站结构：
  推荐→子目录：yourbrand.com/en-us/ (SEO权重集中+管理方便)
  次选→子域名：us.yourbrand.com (独立管理但权重分散)
  不推荐→独立域名：yourbrand.us (权重完全分散+成本高)
```

#### 关键词4大类型

```
短尾(1-2词)：搜索量大+竞争烈+转化低(意图不明) → 品牌建设期使用
长尾(3+词)：搜索量小+竞争低+转化高(意图明确) → 主要目标(80%精力)
商业意图：best/buy/review/vs → 产品页/分类页优化
信息意图：how to/what is/guide → 博客内容+内链到产品页

分配：长尾商业50%(产品页) | 中尾商业20%(分类页) | 长尾信息20%(博客) | 短尾品牌10%(首页)
```

#### 关键词研究5步SOP

```
Step 1：种子词 → 5-10个核心产品词
Step 2：扩展 → Ahrefs/SEMrush + Google Suggest + AnswerThePublic
Step 3：筛选 → 搜索量>100/月 + KD<30(新站)/<50(成熟) + 相关 + 商业意图
Step 4：分组 → 按意图(商业/信息) + 按主题 → 每组5-10词对应一个页面
Step 5：分配 → 每页1个主词+3-5次词，产品页=商业词，博客=信息词
```

#### 竞品关键词分析

```
Step 1：Google搜核心词 → 前10名=SEO竞品 → 选3-5个
Step 2：Ahrefs/SEMrush输入竞品域名 → Organic Keywords → 按流量/难度排序
Step 3：Content Gap/Keyword Gap → 竞品有排名你没有的=机会词
  优先：高搜索量+低难度+相关=最优先 | 竞品5-15位=超越机会
```

> **核心总结**：Amazon排名=销售速度×转化率×关键词相关性。标题前80字符最关键。Search Terms不重复标题已有词、填满250字节。A10更看重站外引流和近期销量。独立站SEO=站内(TDK+Schema+内链)+站外(外链质量>数量，1条DA50>100条DA10)+技术(速度+移动+结构化数据)。关键词80%精力在长尾商业词。
