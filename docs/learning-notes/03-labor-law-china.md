# 中国劳动法实操（老板必知）

> 核心观点：协商解除是首选，违法辞退成本翻倍。

---

## 一、劳动合同

### 1.1 必备条款（劳动合同法第17条）

1. 用人单位名称/地址/法定代表人
2. 劳动者姓名/身份证号
3. 合同期限
4. 工作内容和工作地点
5. 工作时间和休息休假
6. 劳动报酬
7. 社会保险
8. 劳动保护和劳动条件
9. 法律法规规定的其他事项

### 1.2 试用期规定

| 合同期限 | 试用期最长 |
|---------|-----------|
| <3个月 | ❌不得约定 |
| 3个月~1年 | ≤1个月 |
| 1年~3年 | ≤2个月 |
| ≥3年/无固定 | ≤6个月 |

**常见违规**：
- 签1年合同约3个月试用期 → 违法（最长2个月）
- 同一单位同一劳动者约定两次试用期 → 违法
- 单独签试用期合同 → 违法（必须包含在合同内）

### 1.3 试用期工资

```
必须同时满足：
1. ≥ 同岗位最低档工资的80%
2. ≥ 合同约定工资的80%
3. ≥ 当地最低工资标准
三者取最高值！
```

### 1.4 试用期辞退

```
条件：证明"不符合录用条件"
必须有：
1. 入职时书面录用条件（员工签字确认）
2. 考核记录/绩效数据证明不符合
3. 试用期内做出决定
4. 书面通知说明理由

员工试用期辞职：提前3天通知即可（不需要30天）
```

## 二、辞退补偿金

### 2.1 N / N+1 / 2N

| 场景 | 补偿 | 说明 |
|------|------|------|
| 协商解除（单位提出） | N | 双方签协商解除协议 |
| 不能胜任+培训/调岗后仍不能 | N+1 | 提前30天通知或+1代替 |
| 客观情况重大变化 | N+1 | 提前30天通知或+1代替 |
| 经济性裁员 | N | 提前30天通知工会 |
| 合同到期不续签 | N | 单位不续或降低条件 |
| **违法辞退** | **2N** | 无合法理由/程序违法 |

### 2.2 计算公式

```
N = 工作年限 × 离职前12个月平均工资（税前）

工作年限：
- 满1年 = 1个月
- 满6个月不满1年 = 1个月
- 不满6个月 = 0.5个月

封顶：月工资 > 当地社平3倍 → 按3倍算 + 年限最高12年

例：月薪8000，工作2年3个月
- N = 2.5 × 8000 = 20,000元
- 2N = 40,000元（违法辞退）
```

### 2.3 协商解除 vs 单方辞退

| 维度 | 协商解除 | 合法单方辞退 | 违法辞退 |
|------|---------|-------------|---------|
| 补偿 | N | N或N+1 | **2N** |
| 风险 | 低 | 中 | 高（几乎必输仲裁） |
| 建议 | **✅首选** | 谨慎使用 | ❌ |

## 三、竞业限制

### 3.1 适用范围
- **可签**：高管、核心技术人员、掌握保密信息的人员（销售/采购/财务主管）
- **不可签**：普通基层员工、保洁/保安/前台
- ⚠️ 与不适用人员签了→可能无效但仍需付补偿金（白花钱）

### 3.2 补偿金
```
最高法司法解释：离职前12个月平均工资的30%（不低于当地最低工资）
按月支付！不能包含在工资中。
3个月不付 → 员工可解除竞业限制协议
```

### 3.3 违约金
- 通常：补偿金总额的2-5倍（法院支持上限约5倍）
- 建议：约定3倍 + 返还已付补偿金

### 3.4 期限
- **法定上限：2年**
- 核心技术人员：2年 / 高管：1-2年 / 销售主管：1年 / 其他：6个月-1年
- 范围要明确：行业+地域+竞争对手名单

## 四、加班费计算

### 4.1 三种倍数

| 加班类型 | 倍数 | 能否调休替代 |
|---------|------|------------|
| 工作日延时 | **1.5倍** | ❌不能 |
| 周末 | **2倍** | ✅可以（选择权在单位） |
| 法定节假日 | **3倍** | ❌不能 |

```
计算：月薪÷21.75÷8×倍数×小时数

例：月薪8000
- 日工资 = 367.82
- 工作日加班1h = 68.97元
- 周末加班8h = 735.68元
- 节假日加班8h = 1,103.52元
```

### 4.2 加班时间上限
- 每日≤1小时（特殊≤3小时）
- **每月≤36小时**
- 996工作制=月加班128小时，超标3.5倍=严重违法

## 五、常见劳动纠纷TOP5

### 纠纷1：违法辞退
- 仲裁几乎100%判员工赢 → 2N赔偿金
- 预防：协商解除优于单方辞退，必须书面通知+说明理由

### 纠纷2：未签劳动合同
- 后果：从第2个月起双倍工资（最多11个月）、超1年视为无固定期限
- 预防：**入职当天签合同**，一式两份

### 纠纷3：加班费争议
- 仲裁时效2年，员工需举证（考勤/聊天记录/邮件）
- 预防：规范考勤+加班审批+工资条列明加班费

### 纠纷4：工伤赔偿
- 30日内申请工伤认定（超期=承担全部赔偿）
- 未缴工伤保险=全部由企业承担（一次严重工伤>100万）

### 纠纷5：社保争议（与小微企业税务文档一致）
- 参见 `01-sme-tax-china.md` 风险5

---

> **核心总结**：协商解除是最安全的方式（N补偿+低风险）。违法辞退成本是合法的2倍。试用期辞退必须有书面录用条件+考核证据。竞业限制最长2年、补偿金≥月薪30%。加班每月≤36小时、节假日3倍不能调休。入职当天签合同！
