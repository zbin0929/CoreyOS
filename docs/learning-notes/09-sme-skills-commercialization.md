## 二、高优先级品类详解

### 2.1 品类1：财税票据自动化

#### china-tax-law（中国财税法律助手）

**角色**：中国资深财税律师专业助手

**核心工作原则**：
```
1. 法规优先：所有建议必须引用具体法律条文
2. 时效意识：标注政策版本和时效，提示核实最新规定
3. 风险提示：筹划方案必须说明潜在税务风险
4. 专业严谨：区分"合法避税"与"违法逃税"
```

**中国主要税种体系速查**：

| 类别 | 税种 | 核心税率 |
|------|------|---------|
| 流转税 | 增值税 | 13%/9%/6%/小规模3% |
| 流转税 | 消费税 | 烟酒汽车等特定消费品 |
| 流转税 | 关税 | 进出口货物 |
| 所得税 | 企业所得税 | 25%/高新15%/小微优惠 |
| 所得税 | 个人所得税 | 3%-45%七级累进 |
| 财产税 | 房产税 | 从价1.2%/从租12% |
| 财产税 | 土地增值税 | 30%-60%四级超额累进 |
| 行为税 | 印花税 | 合同/凭证 |
| 行为税 | 城建税+教育附加 | 附加税费 |

**工作流程**：
```
税务咨询: 明确业务性质 → 识别涉及税种 → 检索法律法规 → 分析义务+优惠 → 合规建议+风险
税务筹划: 了解业务模式 → 识别筹划空间 → 设计多套方案 → 评估合规性 → 出具书面意见
```

#### contract-review / contract-reviewer（合同风险审查）

**12大风险条款审查清单**：

| 条款 | 审查要点 | 市场标准 |
|------|---------|---------|
| 责任限额 | 是否合理？互惠？ | 12个月费用 |
| 赔偿条款 | 单方还是双方？是否封顶？ | 双方+封顶 |
| 终止条款 | 双方可否便利终止？ | 双方60-90天通知 |
| 自动续约 | 静默续约？退出窗口？ | 90+天通知 |
| IP归属 | 谁拥有工作成果？ | 明确分离 |
| 数据处理 | DPA？违规通知时限？ | 包含DPA |
| 竞业限制 | 范围、期限、地域？ | 1-2年/合理地域 |
| 不可抗力 | 是否包含？覆盖范围？ | 含流行病/网络 |
| 转让条款 | 对方可否未经同意转让？ | 需同意 |
| 保证免责 | "现状"无保证？SLA？ | 有SLA+补救 |
| 保密条款 | 互惠？期限？例外？ | 互惠/3年 |
| 争议解决 | 仲裁vs诉讼？管辖地？ | 中立管辖 |

**市场标准基准表（快速参考）**：

| 条款 | 绿灯（标准） | 黄灯 | 红灯 |
|------|------------|------|------|
| 责任限额 | 12月费用 | 6-11月 | <6月 |
| 竞业期限 | 1-2年 | 3-4年 | 5+年 |
| 自动续约通知 | 90+天 | 60-89天 | <60天 |
| 终止通知 | 双方60-90天 | 单方30天 | 即时 |
| 赔偿 | 双方+封顶 | 不对称 | 不封顶 |
| 代表存续(M&A) | 12-18月 | 24-30月 | 36+月 |
| SLA可用性 | 99.9%+补偿 | 99.5% | 无SLA |
| 数据导出 | 90天标准格式 | 30天 | 无 |
| 涨价限额 | CPI或5%/年 | 10%/年 | 不封顶 |

**Red Flags速查（签约前必查）**：
```
🚩 责任限额 < 6个月
🚩 不封顶的赔偿条款
🚩 "现状"无保证且无SLA
🚩 单方面无通知暂停服务
🚩 单方面修改条款权利
🚩 无便利终止条款
🚩 永久性义务（竞业/非竞争/保密无限期）
🚩 离岸管辖地（BVI/开曼）
🚩 预签利益冲突弃权书
🚩 "自由裁量权"偏向对方
🚩 集体诉讼弃权+强制仲裁
🚩 不对称转让权利
```

**不同合同类型专属检查清单**：

| 合同类型 | 核心关注 |
|---------|---------|
| NDA | 方向（单/双向）、定义范围、期限(3-5年标准)、残留条款 |
| SaaS/MSA | 责任限额、SLA+补偿、暂停权、数据归属+导出、涨价上限 |
| 支付/商户协议 | 保证金/扣款、退款责任、网络规则、自动扣款、结算时间 |
| M&A | 价格结构(现金/股权/业绩对赌)、托管(10-15%)、竞业(2-3年) |
| 中介/经纪协议 | 佣金比例、覆盖买方定义、尾期(12-24月)、排他性 |

**谈判力评估**：
```
有利：大客户+小供应商 / 竞争性市场 / 可替代供应商
不利：创业公司+企业供应商 / 独家供应商 / 监管强制条款
高可协商：双方终止权、补救期、数据导出
中可协商：责任限额、涨价上限
低可协商：网络规则(支付)、监管要求
不可协商：银行卡组织规定、银行法规
```

**管辖地选择参考**：
```
美国：
- Delaware: 公司友好、可预测
- New York: 金融协议、成熟法院
- California: 员工友好、竞业限制基本无效（+ND/OK/MN）
- BVI/开曼: 离岸、诉讼成本高 → 红旗

仲裁机构：
- AAA/JAMS: 美国商业标准
- SIAC/LCIA: 国际、费用高
```

## 三、品类3-8要点速览

### 品类3：电商&零售运营（34个技能）
- 偏跨境电商，包含Amazon/Shopee/TikTok等平台运营技能
- 与CoreyOS跨境电商Pack直接重叠
- 国内电商（淘宝/京东/拼多多）覆盖不足

### 品类4：私域&智能客服（11个技能）
- 核心缺口：企微/微信生态对接
- 有基础客服技能（FAQ、工单、情感分析）
- 对CoreyOS：如果做DTC品牌站，客服技能有价值

### 品类5：商业内容生产（17个技能）
- 覆盖SEO文案、社交媒体、产品描述、邮件营销
- 与跨境电商Listing优化直接相关

### 品类6：人事&行政用工（21个技能）
- 覆盖招聘、薪资、考勤、社保计算
- 小微企业行政工作量大但价值中等
- 对CoreyOS：非核心赛道

### 品类7：门店&简易进销存（10个技能）
- 偏大型仓储配送，小微门店覆盖不足
- 对CoreyOS：与跨境电商库存管理有交集

### 品类8：通用办公自动化（11+47个技能）
- Excel/PDF/邮件等基础办公工具
- 对CoreyOS：底层能力，所有Pack都可能需要

## 四、对CoreyOS的战略启示

### 4.1 Pack商业化优先级推荐

```
Tier 1（首批做）:
├─ 跨境电商Pack（已规划，v0.3.0）
└─ 合同法务Pack（品类2，刚需度⭐⭐⭐⭐⭐，26个现成技能参考）

Tier 2（有客户需求时做）:
├─ 电商客服Pack（品类4，需企微对接）
├─ 财税Pack（品类1，需对接税务系统）
└─ 内容营销Pack（品类5，与电商Pack有协同）

Tier 3（长期）:
├─ 人事行政Pack（品类6）
├─ 门店进销存Pack（品类7）
└─ 宠物医院Pack（单独赛道）
```

### 4.2 合同法务模块的价值

**为什么合同法务应该成为CoreyOS基座能力**：
```
1. 所有行业Pack都需要：跨境电商（供应商合同/物流合同）、
   宠物医院（客户协议/雇佣合同）、任何B端客户
2. 差异化竞争力：本地部署+AI合同审查 → 数据不出企业
3. 26个现成技能可参考，成熟度高
4. 客户付费意愿强（法务成本高，AI替代ROI明显）
```

### 4.3 核心设计模式提取

1. **版本控制模式**（contract）：文档多版本管理+修订标记
2. **多维度审查模式**（contract-review）：12维度+市场基准对比+Red Flags速查
3. **模板化生成模式**（contract-generator）：预定义模板+参数填充
4. **强制免责模式**：AI生成法律文档必须标注"非法律建议"
5. **本地存储模式**（labor-law）：JSON文件索引+条目管理

---

> **总结**：141个小微企业技能中，合同法务（品类2, 26个技能）是CoreyOS最应该关注的方向——刚需度最高、技能成熟度好、且所有行业Pack都能复用。建议在v0.3.0跨境电商Pack中内置基础合同审查能力，独立合同法务Pack可作为v0.4.0候选。
