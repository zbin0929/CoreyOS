## 四、ERP选型决策树

```
Step 1：确定主要销售平台
  只做Amazon？
  ├── 是 → 需要深度数据+广告？
  │         ├── 预算充足 → 积加(最深度)
  │         └── 性价比 → 领星
  │         └── 基础够用 → 店小秘/芒果
  └── 多平台 → 需要海外仓？
            ├── 是 → 易仓/马帮
            └── 否 → 店小秘/芒果/通途

Step 2：确定月销售额
  <$10K(新手) → 免费版(店小秘/芒果/通途)
  $10K-50K(成长) → 店小秘付费/芒果付费/领星
  $50K-200K(扩张) → 马帮/领星/易仓
  $200K+(成熟) → 积加/马帮企业版

Step 3：确定核心需求
  订单处理效率 → 店小秘/芒果
  仓储物流管理 → 马帮/易仓
  财务利润核算 → 积加/领星
  广告投放管理 → 积加/领星
  Listing管理 → 通途/店小秘
  数据分析决策 → 积加/领星
  海外仓管理 → 易仓/马帮

Step 4：试用对比
  → 大多数ERP提供7-15天免费试用
  → 测试：功能满足/操作顺手/客服响应/数据准确
  → 对比2-3家后决定
```

### 选型避坑

```
1. 不要被"功能多"迷惑 → 用不到=浪费钱，核心功能够用就好
2. 不要只看价格 → 便宜的数据可能不准，财务错误=决策失误=更大损失
3. 不要忽视客服 → ERP出问题=全公司停摆
4. 不要频繁换ERP → 数据迁移+团队学习成本高，选定至少用1年
5. 不要忽视数据安全 → 确认安全措施+数据导出功能(不被锁定)
```

  → 易仓★★★★★ | 马帮★★★★★ | 店小秘★★★★ | 芒果★★★★

  → 积加★★★★★ | 领星★★★★★ | 马帮★★★★

  ERP核心(订单/库存/采购/财务/数据)

  广告平台 | 物流渠道 | 财务软件 | 客服工具 | 采购供应商 | 电商平台

## 六、从0到1 ERP上线SOP

```
Step 1：需求梳理(1周)
  → 列出痛点(订单效率?库存混乱?财务不清?多平台困难?)
  → 确定核心需求(最多3个) + 月费预算 + 时间线

Step 2：选型试用(2周)
  → 决策树筛选2-3家 → 免费试用7-15天
  → 测试：功能/操作/数据准确/客服/集成能力 → 打分选定

Step 3：数据准备(1-2周)
  → 产品(SKU/图片/分类/条形码)
  → 库存(各仓库数量/在途/FBA/海外仓)
  → 供应商(联系方式/采购价/周期/MOQ)
  → 财务(期初余额/应收应付/银行账户)
  → ⚠️ 数据清洗：删重复/统一编码/确保准确

Step 4：系统配置(1-2周)
  → 基础(公司/仓库/币种/时区)
  → 平台授权(Amazon/Shopee/eBay/Shopify)
  → 物流(渠道/运费模板/发货规则)
  → 采购(供应商/流程/审批)
  → 财务(科目/成本核算/利润规则)
  → 权限(管理员/运营/采购/财务/仓库)

Step 5：培训试运行(2周)
  Day 1-2：管理员(配置/权限/数据)
  Day 3-4：运营(订单/Listing/广告/数据)
  Day 5-6：采购(下单/供应商/入库)
  Day 7-8：财务(报表/利润/对账)
  Day 9-10：仓库(出入库/拣货/盘点)
  Day 11-14：试运行(新旧并行+每天对比数据)

Step 6：正式上线+优化(持续)
  上线检查：平台授权正常+订单同步+库存准确+物流正常+财务准确+人员培训+旧数据归档
  第1周：每天检查数据 | 第2-4周：每周优化 | 第2-3月：深度定制报表 | 第3月+：稳定持续改进

总时间线：约2.5个月从0到1
  第1周需求 → 第2-3周选型 → 第4-5周数据 → 第6-7周配置 → 第8-9周培训 → 第10周上线
```

---

**跨境ERP选型5条铁律**：
1. **先确定需求再选工具**——痛点驱动选型，核心需求最多3个，用不到的功能=浪费钱
2. **新手用免费版，成长期再付费**——月销<$10K=免费版够用，不要一上来买最贵的
3. **Amazon卖家优先考虑积加/领星**——数据+广告+财务精准；多平台=店小秘/马帮；有海外仓=易仓
4. **ERP上线是项目不是工具**——2.5个月从0到1，数据清洗+配置+培训缺一不可，新旧并行至少2周
5. **选定后坚持用不要频繁换**——数据迁移+团队学习成本高，至少用1年再评估
