|------|-----------------|----------|------------------|---------|
| 核心优势 | 艺术感最强 | 文字理解最准 | 开源免费/本地部署 | 中文理解最好 |

### 1.2 各工具最佳场景

- **Midjourney**：产品概念图/品牌视觉/艺术插画/场景渲染
- **DALL-E 3**：带文字的海报/Logo/信息图/实用图
- **Stable Diffusion**：精确控制(ControlNet)/批量生成/自定义LoRA训练/隐私场景
- **文心一格**：中国风/国潮/中文场景快速出图

### 1.3 商用版权现状

```
美国版权局(USCO)立场：
- 纯AI生成 → 不受版权保护（公共领域）
- 人类有实质创作贡献的AI辅助 → 可受版权保护

安全做法：
1. 生成原创风格（不模仿特定艺术家）
2. 不生成名人肖像/品牌Logo/IP形象
3. 对AI图做二次创作修改
4. 保留生成记录
5. 叠加自己的品牌元素
```

## 三、AI在电商中的应用

### 3.1 产品主图7张SOP

| 张数 | 用途 | AI用法 | 注意 |
|------|------|--------|------|
| 第1张 | 白底主图 | **不建议AI生成！**用真实产品照 | Amazon可能检测AI图 |
| 第2张 | 尺寸规格 | ChatGPT整理参数+Canva模板 | MJ生成装饰背景 |

| 第7张 | 包装配件 | MJ生成开箱场景 | 真实包装图+配件清单 |

**效率对比**：
- 传统（设计师）：5-10天，¥3,000-10,000
- AI辅助：3-4天，¥500-1,500（效率2-3倍，成本降60-85%）

### 3.2 A+页面AI生成

```
Step 1: ChatGPT生成文案框架（品牌故事+5卖点+3场景+5FAQ）
Step 2: MJ生成配图（统一风格 --s 150 --v 6.1 --ar 3:2）
Step 3: Canva排版合成
Step 4: 审核（AI不能编造功能/认证，不能冒充真实照片）
```

### 3.4 小红书AI内容创作SOP

```
Step 1：封面图
  尺寸：3:4竖版(1080×1440px)
  工具：Canva AI(模板) | Midjourney/DALL-E(背景) | 稿定设计(中文模板)
  公式：大字标题+产品图+高对比色 | 人物+产品+场景 | Before/After

Step 2：标题(20字以内+emoji)
  6种公式：
    数字型："5个让你惊艳的XX"
    痛点型："终于解决了XX的烦恼！"
    对比型："用了XX后，再也回不去了"
    好奇型："这个XX竟然这么好用？"
    场景型："上班族必备的XX神器"
    权威型："皮肤科医生推荐的XX"

Step 3：正文(300-500字，口语化+真实感)
  结构：Hook(1-2行吸引)→痛点→解决方案→使用体验→总结推荐
  AI Prompt："请为[产品]写小红书种草笔记，第一人称，口语化，300-500字，
  包含使用场景和感受，分段清晰，适当emoji，不要硬广感"

Step 4：标签(6-10个)
  1-2大标签(#美妆 #护肤) + 3-5中标签(#平价护肤 #敏感肌) + 2-3小标签(#品牌名)
```

#### 小红书爆款笔记5大公式

```
1. 痛点+解决方案："终于解决了[痛点]！" → 痛点→产品→效果→推荐
2. 合集/清单："N个[品类]推荐/必买清单" → 每个1-2句点评
3. 对比测评："[A] vs [B] 实测对比" → 多维度→结论
4. 教程/攻略："[场景]攻略/教程" → 步骤+产品推荐
5. Before/After："用了[产品]后变化太大了" → 前→后→过程

关键要素：封面3秒决定点击 | 标题20字+数字/痛点/emoji | 口语化+真实
互动引导：结尾提问/求赞/求收藏
发布时间：12:00-13:00 / 20:00-22:00
```

## 四、Prompt Engineering最佳实践

### 4.1 六层万能公式

```
Prompt = 主体 + 动作/状态 + 场景/环境 + 光影 + 风格 + 构图/参数

第1层 主体：越具体越好
  ❌ "a product"
  ✅ "a charcoal black TPE yoga mat with alignment lines, 6mm thick"

第2层 动作/状态：静态产品也要描述状态
第3层 场景/环境：决定氛围
第4层 光影：决定质感（soft morning sunlight, golden hour glow）
第5层 风格：决定调性（editorial product photography）
第6层 构图/参数：决定可用性（overhead flat lay --ar 4:3）
```

### 4.2 Midjourney参数速查

| 参数 | 作用 | 电商建议 |
|------|------|---------|
| --ar | 宽高比 | 1:1(产品) / 4:3(Amazon) / 4:5(Instagram) / 9:16(TikTok) |
| --s | 风格化 | 0-50写实 / 100-250电商场景(推荐) / 300-500品牌概念 |
| --c | 混乱度 | 电商0-25 / 创意探索50 |
| --cref | 角色参考 | 品牌模特一致性（只限人物） |
| --sref | 风格参考 | 品牌视觉一致性 |
| --cw | 角色强度 | 0=只参考脸 / 100=脸+服装 |
| --no | 排除元素 | text watermark logo（不要列太多，2-3个） |
| --q | 画质 | 2=最高（V6后差异小） |

### 4.3 风格关键词清单

**摄影风格**：
| 风格 | 关键词 | 适合 |
|------|--------|------|
| 商业产品 | product photography, studio lighting, white background | 产品主图 |
| 编辑级 | editorial photography, magazine style, high-end | 品牌视觉 |
| 生活方式 | lifestyle photography, candid, natural | 场景图 |
| 微距 | macro photography, extreme close-up, detailed texture | 材质展示 |
| 胶片 | film photography, 35mm, Kodak Portra 400, grain | 品牌故事 |
