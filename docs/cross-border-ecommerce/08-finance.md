## 一、跨境电商利润计算

### 1.1 利润计算全公式

**完整计算示例（$30售价的瑜伽垫）**：

```
售价                              $30.00
- 平台佣金（15%）                  -$4.50
- FBA配送费                        -$3.50
- FBA仓储费（月均）                 -$0.30
- 产品成本（¥25÷7.0）              -$3.57
- 头程运费                          -$0.80
- 关税（5%）                        -$0.18
- 广告费（10%）                     -$3.00
- 退货损耗（8%×$15）               -$1.20
- 其他费用                          -$1.30
  ├─ FBA入库配置费 $0.30
  ├─ 低库存费 $0.10
  ├─ 长期仓储费 $0.05
  ├─ 移除/弃置费 $0.05
  ├─ 促销Coupon $0.60
  └─ 其他杂费 $0.20
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
= 净利润                            $11.65
= 净利率                            38.8%

⚠️ 实际运营还有：滞销库存损失、账号风险预留、
   公司运营成本、税费 → 实际净利率低5-15个百分点
```

### 1.2 利润计算常见错误

| 错误 | 表现 | 正确做法 |
|------|------|---------|
| 只算毛利不算净利 | "毛利率40%！"但没算广告退货 | 必须算到净利润 |
| 忘记FBA仓储费 | 只算配送费 | 旺季仓储费是淡季4倍 |
| 退货只算退款 | 忽略处理费+不可售损失 | 退货成本=退款+处理费+损失 |
| 关税算错基数 | 按售价算（应按FOB/CIF） | 美国按FOB价，欧盟按CIF价 |
| 汇率用固定值 | 固定7.0，实际6.8 | 加1-2%汇率风险预留 |
| 忽略Coupon成本 | 设了Coupon忘了算 | 面值×兑换率=实际成本 |
| 不算资金成本 | 库存占用3个月=利息损失 | 月资金成本≈库存金额×1% |

### 1.3 快速利润速算公式

```
净利润 ≈ 售价 × 0.53 - 产品成本 × 1.3

例：$30 × 0.53 - $3.57 × 1.3 = $15.90 - $4.64 = $11.26
（与精确计算$11.65误差<4%，速算够用）

拆解：
- 售价×30% = 佣金+FBA
- 售价×12% = 广告
- 售价×5% = 退货+其他
- 产品成本×1.3 = 含运费关税
```

## 二、各国VAT/GST注册和申报

### 2.1 美国Sales Tax Nexus

**Nexus类型**：

| 类型 | 触发条件 | 说明 |
|------|---------|------|
| 物理Nexus | 有仓库/办公室/员工 | FBA仓库所在州=物理Nexus |
| 经济Nexus | 销售额>$100K 或 交易>200次/年 | 2018年Wayfair案后确立 |
| 点击Nexus | 通过该州推荐链接产生销售 | 部分州有此规定 |

**关键事实**：
- 45个州+DC征收Sales Tax
- 5个免税州：阿拉斯加/特拉华/蒙大拿/新罕布什尔/俄勒冈
- **Amazon Marketplace Facilitator**：Amazon在大多数州代收代缴，但你仍需在有Nexus的州注册并申报

**卖家需要做的事**：
1. 确定Nexus州（FBA仓库所在州 + 销售超阈值的州）
2. 在有Nexus的州注册Sales Tax Permit
3. 定期申报（月/季/年，即使税额为0也要报）
4. 使用TaxJar/Avalara自动化（$20-200/月）

### 2.2 欧盟VAT（IOSS/OSS）

**欧盟VAT三大机制**：

| 机制 | 适用场景 | 申报频率 |
|------|---------|---------|
| IOSS | 欧盟外进口≤€150的B2C远程销售 | 每月 |
| OSS | 欧盟内B2C远程销售 | 每季度 |
| 传统VAT注册 | 在欧盟有仓库/超远程销售阈值 | 每月/季度 |

**实操场景**：
```
场景1：FBA发货到德国仓 → 卖全欧盟
  → 注册德国VAT + OSS申报其他国家

场景2：泛欧FBA（Pan-European）
  → 注册7国VAT（德/法/意/西/波/捷/荷）
  → ⚠️ 最复杂，建议找税务代理

场景3：自发货（无欧盟仓库）
  → ≤€150：IOSS预缴 或 平台代扣
  → >€150：传统进口VAT
```

**欧盟主要国家VAT税率**：

| 国家 | 标准税率 | 优惠税率 | 申报频率 |
|------|---------|---------|---------|
| 德国 | 19% | 7% | 月度/季度 |
| 法国 | 20% | 5.5%/10% | 月度 |
| 意大利 | 22% | 4%/5%/10% | 月度/季度 |
| 西班牙 | 21% | 4%/10% | 季度 |
| 荷兰 | 21% | 9% | 季度 |
| 波兰 | 23% | 5%/8% | 月度 |

### 2.3 英国VAT

```
英国脱欧后规则：

进口VAT：
- ≤£135 B2C：销售时收取（Amazon代扣代缴）
- >£135 B2C：进口时缴纳VAT+关税

注册条件：
- 在英国有FBA库存 → 必须注册
- 远程销售>£70,000/年 → 必须注册
- 税率：20%（标准）/ 5%（优惠）/ 0%（零税率）

申报：
- 季度申报（大多数卖家）
- 年营业额>£85,000 → MTD数字化申报
- C79证书：进口VAT可抵扣
```

**P&L阅读优先级**：
1. 净利润+净利率（赚了还是亏了？）

3. TACOS+广告占比（广告依赖度？）
4. 库存周转天数（资金效率？）
5. 环比变化（趋势向好还是恶化？）

### 3.2 现金流管理

**Amazon回款周期**：
```
默认：每14天结算 → 打款3-5工作日 → 实际到账结算后5-8天

加速方法：
1. Daily Payout（日收款）→ 快7-13天
   条件：账户健康+销售>30天
2. Amazon Lending → 6-15%年化短期贷款
3. Payoneer/PingPong提前垫付 → 0.5-1.5%费率
```

**库存占用现金流模型**：
```
资金占用 = 在途库存 + FBA库存 + 待回款

例：
- 在途500件×$5 = $2,500
- FBA 1000件×$5 = $5,000
- 待回款 $8,000
- 总占用 = $15,500

月销售$15,000 → 资金占用/月销售 = 103% → ⚠️ 危险！

健康指标：
- <80%：健康
- 80-100%：需关注
- >100%：危险
```

**现金流优化策略**：
- **缩短占用**：日收款、小批量多频次发货
- **延迟流出**：供应商月结30-60天、信用卡采购
- **控制库存**：周转天数45-60天、>90天及时清仓
- **现金储备**：至少2个月运营费用
- **融资工具**：Amazon Lending(6-15%) / Payoneer Working Capital(8-18%) / 银行信用证(4-8%)

### 3.3 库存估值方法

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| **FIFO（推荐）** | 先采购的先卖出 | 最常用，利润反映真实 |
| 加权平均 | 总成本÷总数量 | 采购价波动大时 |
| 个别计价 | 每批按实际价算 | 高价值低频采购 |

## 四、税务架构

### 4.1 转让定价：中国→香港→Amazon三角结构

```
中国公司(采购/运营) → 香港公司(销售/收款/品牌) → Amazon平台
```

**各实体角色**：

| 实体 | 角色 | 合理利润率 |
|------|------|-----------|
| 中国公司 | 采购中心+运营中心 | 3-8%(贸易) / 5-12%(生产) |
| 香港公司 | 销售中心+品牌持有 | 10-25% |

**转让定价计算示例**：
```
1688采购价：¥25 → 中国公司加价6% → ¥26.50($3.79)
Amazon售价：$30
香港公司毛利 ≈ $30 - $3.79 - $8.50(FBA) - $3.00(广告) - $2.00(其他) = $12.71

利润主要留在香港（8.25%/16.5% vs 中国25%）
```

**是否需要搭建三角结构？**
- 年利润<30万RMB → 不需要
- 30-100万 → 可考虑（税务节省vs合规成本）
- 100-500万 → 建议搭建（净省3-55万）
- \>500万 → 必须搭建

**合规成本**：¥45,000-160,000/年（注册+年审+审计+转让定价文档+税务顾问）

### 4.2 香港 vs 新加坡

| 维度 | 香港 | 新加坡 |
|------|------|--------|
| 企业税（首档） | 8.25%（首200万港币） | 4.25%（首10万新币） |
| 企业税（标准） | 16.5% | 17% |
| GST/增值税 | 无 | 9% |
| 离岸免税 | ✅ 可申请 | ❌ 汇入需缴税 |
| 注册费 | ¥5K-10K | ¥10K-20K |
| 年维护费 | ¥20K-45K/年 | ¥36K-78K/年 |
| 开户难度 | ★★★★（被拒30-50%） | ★★★（被拒20-40%） |
| 适合 | 纯税务优化 | 东南亚市场+品牌 |

**结论**：纯看税率，香港更优；但新加坡在银行开户和东南亚市场有优势。

### 4.3 避税误区

- 香港公司"零申报"实际有业务 → 严重违法
- 转让定价文档不准备 → 税务局可随意调整+罚款
- CFC规则：受控外国企业利润可能视同分配
- 月利润<¥30K的小卖家搭架构 → 合规成本>节省

## 五、收款与结汇

### 5.1 四大收款工具对比

| 维度 | PingPong | 万里汇 | Payoneer | 连连支付 |
|------|----------|--------|----------|---------|
| 综合费率 | 1.4-2% | 1.3-2% | 1-3.2% | 1.1-1.7% |
| 到账速度 | 1-3工作日 | 1-2工作日 | 2-5工作日 | 1-3工作日 |
| 币种 | 10+ | 10+ | 150+ | 8+ |
| 1688付款 | ✅ | ✅ | ✅ | ✅ |
| VAT付款 | ✅ | ✅ | ✅ | ❌ |
| 开户门槛 | 营业执照+店铺 | 营业执照+店铺 | 身份证即可 | 营业执照+店铺 |
| 大客户费率 | 月收>50万可谈 | 月收>50万可谈 | 阶梯费率 | 月收>30万可谈 |

**建议**：PingPong主用 + 连连备用（双通道防风险）

### 5.2 结汇策略

| 策略 | 适合 | 不适合 |
|------|------|--------|
| 即时结汇 | 月收<$5万、急需RMB | 有外汇判断力的大卖家 |
| 定期结汇 | 月收$5-50万 | 汇率剧烈波动期 |
| 择机结汇 | 月收>$50万、有外汇经验 | 没时间盯汇率 |
| 锁汇 | 大额>$5万、波动大 | 小额、汇率稳定期 |
| 自然对冲 | 有美元支出（1688/VAT） | 所有支出都是RMB |

### 5.3 多币种管理三条铁律

1. **币种匹配**：美元收入付美元支出，减少转换次数
2. **自然对冲优先**：用收款工具直接付1688/VAT = 零汇率损失
3. **不囤外币**：保留1-2个月运营费用外及时结汇

---

> **核心总结**：财务合规是跨境电商的"底线"。利润计算要算到净利润（含所有隐性成本），VAT/Sales Tax必须按时申报，现金流管理比利润更重要——赚钱但现金流断裂是跨境卖家最常见的死法。
