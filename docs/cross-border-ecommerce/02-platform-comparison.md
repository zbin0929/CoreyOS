---

## 一、市场规模与覆盖地区

|------|----------------|---------|-----------|---------|
| Amazon | ~$6000亿 | 美国、欧洲、日本 | 20+ | 稳增（8-12%） |
| Shopee | ~$800亿 | 东南亚、巴西、拉美 | 10+ | 高增（15-20%），巴西爆发 |
| TikTok Shop | ~$300亿+ | 东南亚、美国、英国 | 8+ | 爆发式（100%+），美区刚起步 |
| Temu | ~$300亿+ | 美国、欧洲、澳洲 | 80+ | 爆发式但增速放缓，政策风险大 |

## 三、流量获取方式

|------|--------|---------|-----------|---------|------------|---------|
| Amazon | ⭐⭐⭐⭐⭐ | ⭐ | ❌ | ⭐⭐⭐⭐ | 60-70% | 搜索为王，关键词决定一切 |
| Shopee | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | 40-50% | 搜索+推荐+活动混合驱动 |
| TikTok Shop | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 20-30% | 内容驱动，短视频/直播=流量 |
| Temu | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ | ❌ | <10% | 平台投流，卖家不操心流量 |
| AliExpress | ⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐ | ⭐⭐⭐ | 50-60% | 搜索为主，Choice频道推荐 |
| Lazada | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | 40-50% | 类似Shopee但流量弱 |

- Amazon/eBay/Walmart 是**搜索电商**，SEO和关键词是核心能力

## 六、2025-2026最新政策变化与趋势

| 平台 | 重大政策变化 | 趋势判断 |
|------|------------|---------|
| Amazon | ①入库配置费上调 ②低量库存费正式执行 ③退货标签费新增 ④AI Listing生成工具全面开放 ⑤推出低价专区 | 门槛持续提高，小卖家生存空间收窄；品牌化+精细化是唯一出路 |
| Shopee | ①巴西站本地卖家佣金下调 ②直播/短视频流量加权 ③SIP升级 ④免运费门槛调整 | 从价格战转向内容化；直播电商是最大增量 |
| TikTok Shop | ①美区全量开放 ②达人佣金比例调整 ③本地仓要求提高 ④英国站门槛降低 | 美区是最大机会窗口；内容+达人=核心打法 |
| Temu | ①多国监管调查 ②半托管模式推出 ③双模式并行 ④品质审核趋严 | 政策风险是最大不确定性；半托管模式给卖家更多空间 |
| AliExpress | ①Choice频道全面升级 ②海外仓发货加权 ③俄罗斯市场受影响 ④与Lazada部分打通 | Choice频道是流量密码；俄罗斯市场需观望 |
| Lazada | ①与淘宝/天猫打通选品 ②LGS物流费下调 ③市场份额下滑 | 生存压力最大；适合有阿里生态资源的卖家 |
| eBay | ①推出eBay International Shipping ②AI工具辅助Listing ③重点品类流量倾斜 | 增量有限；适合小众品类深耕 |
| Walmart | ①WFS费率下调抢卖家 ②第三方卖家数量翻倍 ③与TikTok广告合作 | 正在复制Amazon早期路径；现在是入驻窗口期 |
| Mercado Libre | ①巴西税改影响跨境卖家 ②本地仓卖家流量加权 ③金融生态扩展 | 拉美最大机会，但本地化要求高 |

## 七、新手平台选择建议

### 推荐排序

| 优先级 | 平台 | 理由 |
|--------|------|------|
| 🥇 首选 | Shopee | 门槛最低、试错成本最小、学习曲线平缓、东南亚市场增速快 |
| 🥈 进阶 | Amazon | 天花板最高、品牌化必经之路、学会Amazon运营=学会电商核心能力 |
| 🥉 爆发 | TikTok Shop | 增速最快、美区窗口期、内容能力=未来竞争力 |
| 第4 | AliExpress | 多市场覆盖、入门友好、但利润薄 |
| 第5 | Temu | 有工厂资源可以进，纯贸易商不建议 |
| 第6 | Walmart | 有Amazon经验后拓展，不要一上来就做 |
| 第7 | eBay | 小众品类可以做，大众品类不推荐 |
| 第8 | Lazada | 除非有阿里生态资源，否则不如Shopee |
| 第9 | Mercado Libre | 需要拉美本地化能力，新手不推荐 |

### 不同背景的新手怎么选？

| 你的情况 | 推荐平台 | 原因 |
|---------|---------|------|
| 完全零基础、资金<2万 | Shopee | 最低成本试错，个人可开店 |
| 有2-5万资金、想长期做 | Amazon | 投入大但天花板高，学到的能力最通用 |
| 擅长拍视频/做内容 | TikTok Shop | 内容能力直接变现，不依赖广告 |
| 自己有工厂/供应链 | Temu + Amazon | Temu走量清库存，Amazon做品牌利润 |
| 做过国内电商想转跨境 | Amazon | 运营逻辑最接近国内电商 |
| 英语好、想做美国市场 | Amazon → Walmart | 美国市场最大，Amazon先站稳再扩Walmart |
| 会西语/葡语 | Shopee巴西 → Mercado Libre | 拉美是蓝海，语言能力是护城河 |

### 新手三大避坑

1. **不要同时做3个以上平台**——精力分散=全做不好，先精通1个再扩展
2. **不要一上来就做Amazon美国站+大量囤货**——先小批量测款，验证市场再放大
3. **不要忽视合规**——VAT、商标、产品认证，这些"看不见的成本"才是最大的坑
