## 一、Amazon PPC广告体系

### 1.1 SP/SB/SD 三大广告类型对比

| 维度 | SP（Sponsored Products） | SB（Sponsored Brands） | SD（Sponsored Display） |
|------|------------------------|----------------------|----------------------|
| 展示位置 | 搜索结果页+详情页 | 搜索结果顶部（品牌横幅） | 详情页+站外（Twitch等） |
| 广告格式 | 单个产品 | 品牌Logo+3产品+标题 | 单产品（含促销信息） |
| 匹配方式 | 关键词 | 关键词 | 商品/兴趣受众 |
| 计费方式 | CPC | CPC | CPC/CPM |
| 门槛 | 有Buy Box即可 | 需品牌备案 | 需品牌备案 |
| 核心目的 | 推单款、打关键词 | 推品牌、引流店铺 | 抢竞品流量、再营销 |
| 预算占比 | 70-80% | 10-15% | 10-15% |
| 适合阶段 | 全阶段 | 成长期+ | 成熟期 |

**广告展示位置示意**：
```
Amazon搜索"yoga mat"结果页：
┌─────────────────────────────────────────────┐
│  [SB广告] 品牌Logo + 3个产品图              │  ← 顶部横幅
├─────────────────────────────────────────────┤
│  [SP广告] ★★★★☆ $29.99 Sponsored           │  ← 搜索第1行
│  [SP广告] ★★★★☆ $24.99 Sponsored           │  ← 搜索第2行
│  ─────── 自然搜索结果 ───────               │
│  1. 自然结果 #1                              │
│  ...                                        │
│  [SP广告] ★★★☆☆ $19.99 Sponsored           │  ← 搜索底部
├─────────────────────────────────────────────┤
│  产品详情页：                                │
│  [SD广告] "看了这个的人还看了" → 竞品广告     │  ← 详情页侧边
│  [SP广告] "Sponsored products related to"   │  ← 详情页底部
└─────────────────────────────────────────────┘
```

### 1.2 SP广告深度解析

**SP广告3种子类型**：

| 子类型 | 说明 | 使用场景 |
|--------|------|---------|
| 关键词投放 | 对特定关键词出价 | 打核心词排名、拓长尾词 |
| 商品投放（ASIN Targeting） | 对特定ASIN出价 | 抢竞品流量、防御自己ASIN |
| 自动广告 | Amazon算法自动匹配 | 挖词、发现新机会 |

**关键词匹配方式**：

| 匹配方式 | 说明 | 流量量级 | 精准度 | CPC |
|---------|------|---------|--------|-----|
| 广泛匹配（Broad） | 包含关键词+变体+相关词 | 最大 | 最低 | 最低 |
| 词组匹配（Phrase） | 包含词组，顺序不变 | 中等 | 中等 | 中等 |
| 精准匹配（Exact） | 精确匹配（含近义词） | 最小 | 最高 | 最高 |

**各阶段匹配方式使用策略**：
```
新品期：
├── 自动广告 60% + 广泛匹配 40%

成长期：
├── 自动 30% + 广泛 30% + 词组 30% + 精准 10%

成熟期：
├── 精准 40% + 词组 25% + 自动 15% + 商品投放 20%
```

### 1.3 自动广告4种匹配策略

| 策略 | 作用 | 出价建议 |
|------|------|---------|
| 紧密匹配（Close Match） | 验证Listing质量，跑核心词 | 基准出价×1.0 |
| 宽泛匹配（Loose Match） | 发现意想不到的流量入口 | 基准出价×0.7 |
| 替代品（Substitutes） | 出现在竞品页面上 | 基准出价×1.2 |
| 互补品（Complements） | 出现在互补品页面上 | 基准出价×0.5 |

**实操建议**：
- 新品期4种全开，跑2周看数据
- 关掉ACOS>100%且无转化的匹配类型
- "替代品"出价可以高一点——出现在竞品页=直接抢客户

### 1.4 出价策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 动态出价-仅降低 | 自动降低无转化可能的出价 | 新手首选、新品期 |
| 动态出价-提高和降低 | 自动调整高低转化出价 | 成长期、成熟期 |
| 固定出价 | 手动控制不自动调整 | 精细优化阶段 |

**出价实操方法**：
```
Step 1：确定基准出价
  → 从Suggested Bid中间值开始

Step 2：根据数据调整
  → 有转化但排名低 → 加价10-20%
  → 有曝光无点击 → 优化Listing（不是出价问题）
  → 有点击无转化 → 降价或否定该词
  → ACOS过高 → 降价或暂停

Step 3：竞价位置调整（Placement Adjustment）
  → Top of Search：+10-50%（打排名最有效）
  → 产品详情页：0-10%
  → 其余位置：0%
```

## 二、广告投放SOP

### 2.1 新品期（0-30天）：跑数据+打基础

**目标**：获取初始流量+数据，验证产品转化能力

```
预算：$20-50/天

广告结构：
├── 自动广告1个（4种策略全开）
├── 手动广泛匹配1个（5-10个核心大词，建议出价×0.8）
└── 手动精准匹配1个（3-5个最精准词，建议出价×1.2）

出价策略：动态出价-仅降低
位置加价：Top of Search +20-30%
```

**关键动作**：
- ☑ 每天看Search Term Report
- ☑ 有转化的词加入手动精准
- ☑ 无转化高ACOS的词加入否定
- ☑ 新品期容忍高ACOS（80-150%甚至更高）——没有评论=转化率低=正常

**新品期常见错误**：

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 预算太低（<$10/天） | 跑不出数据 | 至少$20/天，确保30+点击 |
| 只开自动广告 | 无法精准控制 | 自动+手动同时开 |
| 急于降ACOS | 排名掉 | 先跑量再优化 |
| 不看Search Term | 浪费钱 | 每天看，及时否定 |
| 不加位置加价 | 错过Top of Search | 至少+20% |

### 2.2 成长期（30-90天）：扩流量+打排名

**目标**：核心关键词打到首页，ACOS逐步下降

```
预算：$50-150/天

广告结构：
├── 自动广告1个（维持跑词）
├── 手动广泛匹配1个（15-30个词）
├── 手动词组匹配1个（10-20个长尾词组）
├── 手动精准匹配1个（5-10个核心词，打排名主力）
├── SB广告1个（品牌备案后开启）
└── 商品投放1个（5-10个竞品ASIN）

出价策略：动态出价-提高和降低
位置加价：Top of Search +30-50%
ACOS目标：40-80%
```

**核心打法：关键词排名推进**：
```
原理：A9算法中，关键词销量=排名权重
     广告出单 → 关键词销量增加 → 自然排名上升 → 自然流量增加

操作：
1. 选3-5个核心关键词
2. 精准匹配+Top of Search加价，确保前3位
3. 持续2-4周，每天5-10个广告出单
4. 自然排名进首页 → 降低出价（自然流量接管）
5. 自然排名稳定后 → 广告转"防守"模式
```

### 2.3 成熟期（90天+）：利润优化+防守

**目标**：ACOS控制在目标值以内，最大化利润

```
预算：$100-500/天（根据销量动态调整）

广告结构：
├── 自动广告（低出价，持续跑词）
├── 手动精准匹配（核心词防守）
├── 手动词组匹配（长尾词收割）
├── 手动广泛匹配（拓新词，低出价）
├── SB广告（品牌词防守+品牌建设）
├── SB视频广告（高转化格式）
├── SD广告-商品投放（抢竞品+防守）
└── SD广告-受众再营销（触达看过未买的用户）

ACOS目标：15-30%（品类差异大）
广告占比控制：广告销量<总销量40%（超过=过度依赖）
```

## 三、关键词否定词管理（进阶）

**否定词管理SOP**：
```
每日：
├── 查看Search Term Report
├── ACOS>100%且0转化的词 → 立即精准否定
└── 完全不相关的词 → 立即词组否定

每周：
├── 汇总本周否定词列表
├── 检查"误杀"（否定词导致曝光下降>20%？）
└── 更新否定词文档

每月：
├── 全面审查否定词库
├── 清理"过时"否定词（季节性词可能需重新开放）
├── 否定词效率 = 节省金额 ÷ 总花费，目标>15%
└── 归档否定词决策记录
```

**否定词决策树**：
```
这个搜索词是否与我的产品相关？
├─ 完全不相关 → 词组否定
├─ 相关但转化差 → 精准否定
├─ 相关但ACOS高 → 先降价，不行再否定
└─ 相关且ACOS可接受 → 保留
```

**"误杀"场景**：
- 词组否定"cheap" → 连"cheap yoga mat"也被否定 → **改用精准否定**
- 否定竞品品牌词 → "Lululemon alternative yoga mat"也被否定 → **只精准否定品牌词本身**

## 四、ACOS优化进阶

**分时调价策略**（美国市场EST时间）：
```
00:00-06:00  低转化（深夜）       → 降低出价20-40%
06:00-09:00  上升（早起通勤）
09:00-12:00  高峰（工作间隙购物） → 提高出价10-30%
12:00-14:00  高峰（午休购物）     → 提高出价10-30%
14:00-18:00  中等（工作时间）
18:00-21:00  高峰（下班后购物）   → 提高出价10-30%
21:00-24:00  下降（准备睡觉）
```

**分ASIN出价策略**：
```
同一广告中不同变体转化率差异巨大：
├── 黑色：CVR 12%，ACOS 20% → 加大出价
├── 紫色：CVR 8%，ACOS 35% → 维持出价
├── 粉色：CVR 5%，ACOS 80% → 降低或暂停
└── 绿色：CVR 15%，ACOS 15% → 最大化出价

策略：高转化变体单独建活动给高出价，低转化变体单独控预算
```

## 六、Listing优化：主图7张规划 + 视频

**7张图片规划**：
```
第1张：主图（白底，决定CTR）
  → 纯白背景，产品占85%+，最吸引人的角度

第2张：尺寸/规格图（信息图）
  → 标注尺寸、厚度、重量等关键参数
  → 减少因尺寸不符导致的退货

第3张：功能卖点图1
  → 展示核心功能（如瑜伽垫防滑纹理特写）

第4张：功能卖点图2
  → 展示第二核心卖点（如厚度/回弹性）

第5张：使用场景图
  → 真人使用场景，让用户"代入"

第6张：对比图/细节图
  → 与旧款/竞品对比，或展示细节

第7张：包装/配件图
  → 展示包装内容物，管理用户预期
```

**视频优化**：

| 视频类型 | 时长 | 优先级 |
|---------|------|--------|
| 产品演示 | 30-60秒 | 最重要，前3秒展示最惊艳效果 |
| 使用教程 | 60-120秒 | 减少"不会用"退货 |
| 品牌故事 | 30-60秒 | 建立情感连接 |

**视频制作标准**：
- 分辨率：≥1920×1080
- 前3秒必须有Hook
- 有字幕（60%+用户静音看视频）
- 真人出镜>纯产品展示（转化率高30%+）
- 手机拍+剪映/CapCut即可

## 七、Shopee广告体系

> 东南亚市场的广告逻辑和Amazon有本质区别——Shopee更像"淘宝模式"，流量更碎片化，广告更偏"逛"的场景。

### 7.1 关键词广告（Shopee Keywords Ads）

```
展示位置：
  1. 搜索结果页顶部（前2-4个位置，带"Ad"标签）
  2. 搜索结果页中间穿插（每隔若干自然结果插入1个广告位）
  3. 搜索结果页底部

触发机制：
  → 买家搜索特定关键词时展示
  → 类似Google搜索广告/Amazon Sponsored Products

计费方式：
  → CPC（按点击付费）
  → 实际扣费 = 下一名出价 ×（你的质量分 ÷ 下一名质量分）+ 0.01
  → 实际扣费 ≤ 你的出价

竞价机制：
  → 广告排名 = 出价 × 质量分（Quality Score）
  → 质量分由以下因素决定：
    - 预期点击率（基于历史数据）
    - 广告相关性（关键词与Listing匹配度）
    - 落地页体验（产品页质量/价格竞争力/评分）

适用场景：
  ✅ 有明确搜索意图的品类（3C/家电/美妆工具）
  ✅ 核心关键词排名靠后需要提升曝光
  ✅ 新品需要精准流量
  ✅ 推广特定功能/属性的产品

不适合：
  ❌ 搜索量极低的冷门品类
  ❌ Listing质量差（低评分/差评多/图片差）→ 质量分低→出价再高也排不上
```

### 7.2 关联广告（Discovery / Related Ads）

```
展示位置：
  1. 产品详情页——"相似推荐"区域
     → 买家在看竞品A的产品页时，你的产品出现在推荐位
  2. 产品详情页——"猜你喜欢"区域
  3. 购物车页面——"推荐搭配"区域
  4. 订单完成页——"你可能还喜欢"区域
  5. Shopee首页——"每日发现"区域

触发机制：
  → 基于Shopee推荐算法，在相关场景中展示
  → 不需要买家主动搜索
  → 类似Amazon Sponsored Display / 淘宝的"猜你喜欢"

计费方式：
  → CPC（按点击付费）
  → 同样是竞价排名机制

竞价机制：
  → 广告排名 = 出价 × 相关性得分
  → 相关性得分由以下因素决定：
    - 产品与展示页面的品类相关性
    - 产品价格竞争力
    - 产品评分和销量
    - 买家历史行为匹配度

适用场景：
  ✅ 视觉驱动型品类（服装/饰品/美妆/家居装饰）
  ✅ 冲动消费型产品（低价/颜值高/新奇特）
  ✅ 互补产品推荐（手机壳出现在手机详情页）
  ✅ 竞品拦截（你的产品出现在竞品详情页）
  ✅ 新品冷启动（不需要搜索量也能获得曝光）

不适合：
  ❌ 差异化极小的标品（价格战严重）
  ❌ 需要精确搜索意图的专业产品
```

### 7.3 发现广告（Shopee Ads - Discovery / 首页信息流）

```
展示位置：
  1. Shopee首页——"每日发现"信息流
  2. Shopee首页——"为你推荐"区域
  3. 各品类页面——推荐信息流
  4. 活动专题页——推荐区域

触发机制：
  → 基于用户画像+浏览历史+购买行为的个性化推荐
  → 最大曝光量级，类似抖音信息流广告/淘宝首页推荐

计费方式：
  → CPM（按千次展示付费）或 CPC（按点击付费）
  → 部分市场支持oCPM（优化目标转化出价）

竞价机制：
  → 广告排名 = 出价 × 预估CTR × 预估CVR
  → eCPM = 出价 × CTR × CVR × 1000
  → 系统预估你的广告被点击和转化的概率
  → 高CTR+高CVR的产品可以用更低出价获得展示

适用场景：
  ✅ 品牌曝光/新品上市造势
  ✅ 大促期间抢占首页流量
  ✅ 视觉吸引力强的产品（主图决定CTR）
  ✅ 已验证高转化率的产品放量

不适合：
  ❌ 新品未验证转化率（CPM模式下可能烧钱没转化）
  ❌ 主图不吸引人的产品（CTR低=eCPM低=展示少）
  ❌ 预算有限的小卖家
```

### 7.4 三种广告类型对比总表

| 维度 | 关键词广告 | 关联广告 | 发现广告 |
|------|----------|---------|---------|
| 展示位置 | 搜索结果页 | 产品详情页/购物车/订单页 | 首页信息流/品类推荐 |
| 触发方式 | 买家主动搜索 | 算法推荐（场景关联） | 算法推荐（用户画像） |
| 计费方式 | CPC | CPC | CPM/CPC |
| 流量意图 | 强意图（精准） | 中意图（浏览） | 弱意图（发现） |
| 转化率 | 最高（3-8%） | 中等（1-4%） | 最低（0.5-2%） |
| 单次点击成本 | 中-高 | 低-中 | 低 |
| 适合阶段 | 全阶段 | 成长期+成熟期 | 成熟期放量 |
| 核心优化指标 | CTR+CVR+关键词 | 相关性+CTR | CTR+eCPM |
| 预算占比建议 | 50-70% | 20-30% | 10-20% |

### 7.5 关键词广告出价策略

```
阶段1：测词期（第1-7天）
  目标：找到有效关键词
  出价：系统建议出价的1.2-1.5倍
  → 高出价=确保展示量=快速积累数据

  关键动作：
  ☑ 每天检查搜索词报告
  ☑ 否定不相关词（避免浪费预算）
  ☑ 保留CTR>1%的关键词
  ☑ 淘汰CTR<0.3%且花费>预算10%的词

阶段2：优化期（第8-21天）
  目标：提升ROAS
  高ROAS词（>目标值）→ 加价10-20%（抢更多流量）
  中ROAS词（≈目标值）→ 维持出价
  低ROAS词（<目标值但>0）→ 降价20-30%
  零转化词（有花费无出单）→ 暂停或大幅降价

  关键动作：
  ☑ 每周调整1-2次出价（不要每天调）
  ☑ 关注"搜索词报告"中的高转化长尾词
  ☑ 将高转化搜索词加入手动投放

阶段3：稳定期（第22天起）
  目标：维持排名+控制成本
  ☑ 每周检查1次
  ☑ 关注竞品动态（竞品降价/加广告=你可能需要调整）
  ☑ 大促前3天提高出价20-30%
  ☑ 大促后恢复原出价

关键词选择技巧：
  1. 品类大词（搜索量大但转化低）
     → 例："手机壳"  出价：中等，预算占比<20%
  2. 属性词（搜索量中等，转化中等）
     → 例："iPhone 15 手机壳 透明"  出价：中高，预算占比40-50%
  3. 长尾词（搜索量小但转化高）
     → 例："iPhone 15 Pro Max 透明防摔手机壳 磁吸"  出价：低-中，预算占比30-40%
  4. 否定词（必须设置！）
     → 卖iPhone手机壳→否定"Samsung""华为""小米"
     → 卖高端产品→否定"便宜""免费""二手"
```

### 7.6 关联广告出价策略

```
出价原则：
  → 起始出价=系统建议出价
  → 关联广告的CPC通常低于关键词广告
  → 因为流量意图较弱，出价过高容易亏

优化技巧：
  1. 选对"关联目标"
     → 策略A：出现在竞品详情页（拦截竞品流量）
       选择价格比你高/评分比你低的竞品
     → 策略B：出现在互补产品详情页
       卖手机壳→出现在手机膜详情页

  2. 优化主图（CTR的决定因素）
     → 关联广告展示的是产品主图+价格+评分
     → 主图必须：清晰+有吸引力+突出卖点
     → A/B测试不同主图

  3. 价格策略
     → 关联广告的买家在"比较"状态
     → 价格竞争力决定点击率
     → 配合Voucher/折扣提升CTR
```

### 7.7 发现广告出价策略

```
出价原则：
  → CPM模式：从系统建议出价开始
  → CPC模式：比关键词广告低20-30%
  → oCPM模式（如可用）：设定目标CPA，系统自动优化

优化技巧：
  1. 主图是第一生产力
     → 发现广告=信息流=买家在刷→必须3秒吸引注意力
     → 测试：白底vs场景vs模特图
  2. 定向优化
     → 基于品类兴趣定向
     → 基于行为定向（近期浏览过同品类）
     → 排除已购买客户
  3. 预算控制
     → 小预算测试→ROAS达标→逐步放量
     → 大促前加预算，大促后立即降回
```

| 维度 | Shopee广告 | Amazon PPC |
|------|-----------|------------|

| 优化难度 | 中等（规则简单但数据有限） | 较高（规则复杂但数据丰富） |

**5个最关键的差异**：
1. **流量意图**：Amazon买家"搜了就买"→关键词广告是绝对主力；Shopee买家"逛着买"→三管齐下
2. **CPC差异巨大**：Amazon美国站$0.5-3.0，Shopee东南亚$0.05-0.5，但转化率也低，最终ROAS差异没CPC差异大
3. **大促效应**：Shopee 9.9/11.11期间流量翻5-10倍，CPC翻2-3倍；Amazon Prime Day流量翻2-3倍
4. **自然流量**：Shopee自然流量占比低（30-50%），不投广告几乎没流量；Amazon自然流量高（50-70%）
5. **数据颗粒度**：Amazon广告数据非常详细；Shopee相对粗略，优化更多靠经验+测试

**Shopee广告5条铁律**：
1. 新品期关键词广告为主（70%），测词出单优先
2. 成长期三管齐下，关联广告拦截竞品流量
3. 成熟期发现广告放量，大促前加码
4. ROAS不是越高越好，是"利润最大化"
5. 大促决定全年——9.9/11.11/12.12占全年30-50% GMV

## 八、TikTok Shop广告体系

> TikTok是"内容驱动购买"，不是"搜索驱动购买"——和传统电商PPC完全不同的物种。

### 8.1 信息流广告（In-Feed Ads）

```
展示位置：
  1. TikTok "For You"页面信息流中（与普通视频混排，带"Ad"标签）
  2. TikTok视频详情页
  3. TikTok搜索结果页（2025年新增）

触发机制：用户刷For You页时自然出现，基于兴趣+算法推荐

计费方式：CPC / CPM / oCPM（推荐oCPM，系统自动优化到转化目标）

投放流程：
  Step 1：创建广告组→选择目标（流量/转化/应用安装）
  Step 2：选择受众定向
  Step 3：设置预算+出价
  Step 4：上传视频素材+文案+CTA
  Step 5：选择落地页（TikTok Shop商品页/独立站）
  Step 6：提交审核→上线

适用：所有TikTok Shop卖家主力广告 / 新品冷启动 / 爆款放量
不适合：没有视频素材的卖家
```

### 8.2 Spark Ads（火花广告）

```
展示位置：与In-Feed Ads相同（For You信息流），但展示达人原生视频

核心机制：
  → 借用达人已发布的视频作为广告素材
  → 保留达人头像/昵称/互动数据
  → 看起来像自然内容，信任度更高
  → 底部增加"Shop Now"等CTA按钮

与In-Feed Ads的区别：
  In-Feed = 品牌自己视频 → 明显是广告
  Spark   = 达人视频 → 像自然内容，信任度更高

投放流程：
  Step 1：与达人合作，达人发布带货视频
  Step 2：获得达人的Spark Ads授权（Creator Tools中开启）
  Step 3：在Ads Manager中选择该视频作为广告素材
  Step 4：设置定向+预算+出价
  Step 5：广告上线

⚠️ Spark Ads的ROI通常比In-Feed高30-50%（用户更信任达人推荐）
```

### 8.3 DPA动态商品广告（Dynamic Product Ads）

```
核心机制：
  → 上传产品目录（Product Catalog）到TikTok
  → 系统根据用户行为自动匹配产品
  → 动态生成广告：产品图+价格+名称
  → 不需要单独制作视频素材！

广告格式：
  1. 视频DPA：产品图自动合成视频（轮播/滑动）
  2. 图片DPA：产品图+价格标签的静态卡片
  3. 轮播DPA：多产品滑动展示

适用：SKU多的卖家（100+SKU）/ 再营销 / 动态推荐
不适合：SKU少的卖家（<10个，手动做In-Feed更灵活）

⚠️ DPA再营销ROI极高（ROAS可达5-10），是最高ROI的广告类型
```

### 8.4 直播间引流广告（Live Shopping Ads）

```
展示位置：
  1. For You信息流——直播间实时预览卡片（带"LIVE"标签+观众人数）
  2. TikTok Live专区推荐
  3. 搜索结果页

核心机制：广告直接引流到正在进行的直播间，仅在直播期间投放

关键指标：
  → 进房率（CTR）目标>3%
  → 停留时长目标>3分钟
  → 直播间转化率目标>2%
```

### 8.5 TopView / 品牌挑战赛

```
TopView（开屏广告）：$50,000-150,000/天，每天仅1个品牌
品牌挑战赛（Hashtag Challenge）：$100,000-300,000/次
品牌效果（Branded Effects）：$30,000-100,000/次

⚠️ 大品牌玩法，小微企业不需要关注。预算集中在In-Feed/Spark/DPA/Live即可。
```

### 8.7 受众定向方式

```
1. 兴趣定向：系统预定义的兴趣标签（美妆/健身/科技/时尚等）
2. 行为定向：基于用户在TikTok上的行为（视频互动/创作者关注/Hashtag浏览）
3. 自定义受众：上传客户列表(邮箱/手机号)/Pixel追踪/App活动/TikTok互动
4. Lookalike受众：基于种子受众扩展（1%最精准→10%最宽泛）
5. 再营销：浏览未购买/加购未购买/已购买交叉销售，ROAS通常比冷流量高3-5倍

定向组合策略：
  冷启动（无数据）：兴趣+行为定向 → 宽泛覆盖积累数据
  成长期（少量数据）：兴趣+Lookalike 1-3% → 扩大精准受众
  成熟期（数据充足）：Lookalike 1-5% + 再营销 + 自定义受众

⚠️ TikTok建议受众规模>100万，让算法充分学习
```

### 8.8 创意素材要求

```
视频尺寸：9:16竖屏（推荐1080×1920）
时长：推荐15-30秒（最佳完播率区间）
格式：MP4/MOV，<500MB，H.264/H.265

视频结构黄金公式（15-30秒）：
  0-3秒：Hook（钩子）→ 痛点开场/视觉冲击/悬念/数据
  3-10秒：Problem→Solution → 展示痛点+产品出现
  10-20秒：Demo/Proof → 产品实际使用+特写+效果展示
  20-25秒：Offer → "50% OFF today only"
  25-30秒：CTA → "Tap the link to shop now"

完播率基准：
  5-10秒视频：25-35%（优秀40%+）
  11-15秒：20-30%（优秀35%+）
  16-30秒：15-25%（优秀30%+）
  31-60秒：8-15%（优秀20%+）

提升完播率7个技巧：
  1. 前3秒必须有Hook
  2. 每2-3秒切换画面/角度
  3. 加字幕（60%用户静音刷TikTok）
  4. 产品前3秒出现
  5. 原生TikTok风格拍摄
  6. 音乐/音效配合节奏
  7. 结尾有明确CTA

CTA按钮：Shop Now（最常用）/ Buy Now / Order Now / Learn More
```

### 8.9 TikTok Shop广告投放SOP

```
   → 基于长期购买行为和品牌偏好
   → 例："Fitness Enthusiast" / "Organic Living"
   → 规模大，适合品牌认知

3. Amazon购买行为受众 ★★★★★精度
   → 核心优势：真实购买数据（其他平台无法复制）
   → 品类购买者/品牌购买者/竞品购买者/消费能力分层
   → 例："过去90天购买过$50+瑜伽垫的用户"

4. Lookalike受众 ★★★★☆精度
   → 基于种子受众（购买用户/高价值客户）扩展
   → 规模比例：1%/3%/5%/10%

5. Retargeting受众 ★★★★★精度
   → 产品浏览未购买/加购未购买/品牌搜索未购买/竞品浏览者
   → 转化率最高

受众组合策略（全漏斗）：
  认知：Lifestyle + Lookalike 5-10%
  考虑：In-Market + 竞品浏览者
  购买：Retargeting（核心）+ 竞品购买者
  忠诚：品牌购买者 + 重复购买者
  ⚠️ 每阶段排除上一阶段受众，避免浪费
```

### 10.6 DSP关键指标

```
DPVR（详情页浏览率）= 详情页浏览次数 ÷ 广告展示次数
  → Display 0.1-0.5% | Video 0.5-2% | 再营销 0.5-1.5%

ROAS = 展示带来的销售额 ÷ CPM花费
  → 认知 1.0-2.0 | 考虑 2.0-4.0 | 购买 3.0-8.0 | 再营销 5.0-15.0
  → ⚠️ DSP ROAS通常低于SP，因包含大量认知/考虑展示

NTB%（新品牌购买占比）= 新品牌客户订单 ÷ 总订单
  → 认知 70-90% | 考虑 50-70% | 购买 30-50% | 忠诚 10-20%
  → ⚠️ DSP最重要的差异化指标，SP无法区分新老客户

品牌搜索量提升 = 看过DSP广告用户的品牌搜索量 ÷ 未看过的
  → 认知广告提升10-30% | 考虑广告提升20-50%

指标组合诊断：
  高DPVR+低ROAS → 产品页/价格/评论有问题
  低DPVR+高ROAS → 广告创意不够吸引人
  高ROAS+低NTB% → 过度收割老客户，需扩大认知预算
  低ROAS+高NTB% → 正常（新客获取成本高），看LTV
```

### 10.7 中小卖家DSP适合度评估

```
适合投DSP的条件（需同时满足）：

  ✅ SP/SB/SD广告体系成熟（ACOS稳定）
  ✅ 月广告预算 > $10K（可分配给DSP）
  ✅ 有明确的品牌建设目标
  ✅ 产品线≥3个ASIN

不适合投DSP：
  ❌ 年GMV < $500K
  ❌ SP/SB广告还没优化好
  ❌ 只追求短期ROAS
  ❌ 月广告预算 < $5K

中小卖家DSP平替方案：
  1. SD受众定向 = DSP"低配版"（$1/天起步）
  2. SB品牌视频 = 轻量级视频广告
  3. Amazon Brand Story = 品牌展示模块
  4. 站外引流(Google/FB) = 类似受众定向但成本更低
```

### 10.8 Amazon DSP vs Google GDN对比

| 维度 | Amazon DSP | Google GDN |
|------|-----------|-----------|
| 数据来源 | 购物行为（真实购买） | 搜索+浏览行为 |
| 数据精度 | ★★★★★ | ★★★☆☆ |
| 转化率 | 0.5-3% | 0.1-0.5% |
| CPM | $2-8(Display)/$25-50(OTT) | $0.5-3 |
| ROAS基准 | 2.5-6.0 | 1.0-3.0 |
| 最低预算 | $10K/月 | $1/天 |
| 转化路径 | 短（站内闭环购买） | 长（站外→独立站→购买） |
| 品牌安全 | 高（Amazon控制环境） | 中（第三方网站参差不齐） |
| 适合 | Amazon大卖家/品牌方 | 独立站卖家/全渠道卖家 |

**核心差异**：DSP用购买数据定向（最精准），GDN用搜索数据（覆盖广但精度低）。两者互补：DSP主攻Amazon转化+GDN主攻品牌曝光+独立站引流。

**Amazon DSP 5条铁律**：
1. DSP是品牌武器不是卖货工具——不要用DSP ROAS和SP ACOS直接对比
2. 购买行为数据是DSP护城河——只有Amazon有真实购买数据
3. 全漏斗思维——只投购买层=浪费DSP核心价值
4. NTB%是衡量DSP效果的核心指标——品牌成长期追求NTB%>50%
5. 中小卖家先从SD开始——年GMV<$1M不建议投DSP

### 11.4 AI智能出价工作原理

```
核心逻辑：预测每个关键词在不同出价下的表现→选择最优出价

Step 1：数据收集（历史广告+竞争环境+产品+时间数据）
Step 2：特征工程（关键词/时间/产品/竞争特征）
Step 3：模型训练（XGBoost/LightGBM预测CTR/CVR/CPC）
Step 4：出价优化（目标函数ACOS/ROAS/排名 + 预算/利润约束）
Step 5：执行+反馈（自动调整→收集新数据→重新训练）

出价频率：PacVue/Perpetua每小时 | Teikametrics/Sellozo每日

AI出价优势场景：
  大促期间 ★★★★★（自动识别竞争变化）
  新品期 ★★★★☆（缩短测试周期）
  稳定期 ★★★☆☆（差异不大）
  长尾词(数据少) ★★☆☆☆（不如经验判断）

AI出价局限性：
  1. 数据依赖：关键词需>30天+>30次点击才有效
  2. 黑天鹅事件：无法预测突发（竞品断货/政策变化）
  3. 过度优化：可能短期ACOS好但长期排名下降
  4. 冷启动：新品无数据，先手动再切AI

实际效果（行业平均）：
  ACOS改善10-25% | ROAS提升15-30% | 管理时间节省60-80%
```
